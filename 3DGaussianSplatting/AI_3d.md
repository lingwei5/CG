# 神经渲染 可微渲染 Nerf 3dgs 介绍一下演化进程重要论文技术代表，与传统光栅化 pbr对比
这条线本质上不是“NeRF 替代 PBR”，而是**渲染目标从“按物理方程画一帧”变成“从多视图照片反推一个可微场景表示”**。可微渲染是桥梁，NeRF 是把场景塞进 MLP 权重的极端形式，3DGS 是把表示重新拉回显式图元、但保留可微训练回路的折中。

---

## 1. 起点：传统光栅化 / PBR 为什么“不能反向”

经典实时管线是：

网格 → 顶点变换 → 光栅化覆盖测试 → 深度 z-buffer → 片元着色（Phong / PBR BRDF）→ 输出图像

问题出在两个离散操作：

- **像素–三角形归属**是二值判断（inside/outside）
- **遮挡**是 hard argmin（取最前面那个片元）

这两个地方几乎处处梯度为 0，改一下顶点位置只要没跨过像素边界，图像完全不变。所以你不能写：

```
loss(image, photo) → backprop → 顶点/材质/光照
```

PBR 本身（Cook-Torrance BRDF、金属度/粗糙度、环境光照）解决的是“给定几何和材质后颜色对不对”，不是“怎么从图片反推几何”。它强在：
- 材质参数有明确物理含义
- 可重光照、可编辑、可接入 GI
- 硬件光栅化/RT Core 极成熟

弱在：
- 要高质量新视角，得先把几何恢复出来
- 薄结构、半透明、毛发、镜面反射、无几何先验时很吃力

---

## 2. 可微渲染：把 rasterizer 变成可反传的模块

代表思路（2014–2019）：

- **OpenDR**（Loper & Black 2014）：数值差分近似梯度
- **Neural 3D Mesh Renderer / N3MR**（Kato 2018）：把可微渲染接进神经网络
- **Soft Rasterizer**（Liu et al. 2019）：把覆盖测试换成 sigmoid 软归属，把 z-buffer 换成概率加权混合

核心技巧就是一句话：
> 把 “这个像素归哪个三角形” 改成 “每个三角形按距离给这个像素一点权重”

于是梯度能从轮廓 loss、颜色 loss 流回顶点位置、姿态、相机参数。

这一阶段**表示还是 mesh**，只是渲染器可微了。适合单图重建、姿态估计、SMPL 人体拟合。

---

## 3. NeRF（2020）：场景不再存成网格，存成 MLP 权重

Mildenhall et al., *NeRF: Representing Scenes as Neural Radiance Fields*

### 表示
一个全连接 MLP：

```
(x, y, z, θ, φ) → (RGB, σ)
```

- σ（density）只依赖位置 → 几何
- RGB 依赖视角方向 → 高光/视相关

场景“存在网络权重里”，不存 voxel、不存 mesh，省存储（~5MB/场景）。

### 渲染
沿相机射线采样点 → 网络算颜色与密度 → 经典体渲染积分：

```
C = Σ T_i (1-exp(-σ_i δ_i)) c_i
T_i = exp(-Σ σ_j δ_j)
```

整个链路可微，loss 直接用照片 RGB。

### 两个关键 trick
1. **Positional encoding**：原始坐标过一层 sin/cos 高频映射，抵消 MLP 频谱偏置，否则出来糊
2. **Hierarchical sampling**：coarse net 先估密度分布，fine net 按重要性采样，别把算力浪费在空气里

### 意义
第一次用“仅多视图 RGB + 位姿”训出复杂真实场景的新视角，不需要 GT 几何。

### 短板
- 每条射线要查几十次 MLP → 渲染慢（原始版秒级/帧）
- 训练按场景拟合，几小时到一天
- 几何是密度场，不是表面；难做 PBR 重光照、碰撞、编辑
- 空区域也要走采样

### 演化支线（简要）
- **Mip-NeRF**（2021）：抗锯齿，圆锥采样
- **Instant-NGP**（Müller 2022）：hash grid 编码，训练降到分钟级
- **PlenOctrees / TensoRF**：预计算或张量分解换实时
- **NeRF in the Wild**：非受控照片集
- **物理扩展**：NeRV、TensoIR 把辐射拆成 albedo+BRDF+光照

---

## 4. 3D Gaussian Splatting（2023）：把 NeRF 的“连续场”换成显式高斯云

Kerbl, Kopanas, Leimkühler, Drettakis, *3D Gaussian Splatting for Real-Time Radiance Field Rendering*

### 表示
场景 = 一堆各向异性 3D Gaussian，每个存：

- 中心 μ
- 协方差 Σ（用 scale + rotation 参数化，保证半正定）
- opacity α
- SH 系数（视相关颜色）

初始化来自 SfM 稀疏点云。

### 渲染
不是 ray-march MLP，而是：
1. 把 3D 协方差投影到屏幕 → 2D 椭圆 splat
2. 按 tile 分块、按深度排序
3. front-to-back α 混合
4. 早期终止

这其实是**“光栅化外衣 + 体渲染合成规则”**，所以能跑满 GPU 光栅管线。

### 优化
交替做：
- 梯度下降更新高斯参数
- **Adaptive Density Control**：梯度大的高斯 clone / split，opacity 过低的 prune

### 为什么重要
同时拿到三件事：
- 质量持平 Mip-NeRF360
- 训练几十分钟
- 1080p 实时（30fps+，常 100+）

NeRF 是“隐式连续场 + 重网络推理”，3DGS 是“显式图元 + 轻量可微光栅”。

### 短板
- 高斯不是表面网格 → 拓扑/法向不明确
- 几何–外观纠缠：一个高斯既是几何也是材质也是高光
- 原生不支持重光照，SH 颜色绑死训练视角分布
- 大场景高斯数量爆炸，存储压力大
- 依赖位姿准、覆盖够

后续方向基本都是在补这些洞：
GaussianAvatar / 动态、2DGS（曲面对齐）、PhysGaussian、Relightable 3DGS、压缩/LOD。

---

## 5. 四者对照（核心维度）

| 维度 | 光栅化 + PBR | 可微 mesh 渲染 | NeRF | 3DGS |
|---|---|---|---|---|
| 场景表示 | 三角网 + 纹理/材质 | 三角网 | MLP 隐式场 | 显式 3D 高斯 |
| 可微性 | 否（硬覆盖/z） | 是（软光栅） | 是（体渲染） | 是（splat α-blend） |
| 输入监督 | 需几何/材质 | 图片+mask/轮廓 | 多视图 RGB+位姿 | 多视图 RGB+位姿 |
| 几何输出 | 精确 mesh | 精确 mesh | 密度场（隐式） | 点状高斯（非水面） |
| 材质/BRDF | 显式可重光照 | 可接 BRDF | 无，绑死视角 | SH 颜色，难重光照 |
| 渲染速度 | 极快 | 快 | 慢（原始） | 实时 |
| 训练成本 | 无（直接建模） | 低–中 | 高 | 中 |
| 编辑/物理交互 | 强 | 强 | 弱 | 中弱 |

## 6. 一句话定位三者关系

- **可微渲染**：让“图像差”能反传到场景参数，是方法论底座
- **NeRF**：把场景表示彻底神经隐式化，质量上限高、但慢
- **3DGS**：保留可微体渲染的训练逻辑，把表示显式化换回光栅化速度
- **PBR 光栅化**：不是同一层东西——它假设几何/材质已有，负责“画得物理正确”

当前工业界常见混合形态：
- 用 NeRF/3DGS 做捕获与新视角
- 用 mesh + PBR 做游戏/引擎里的可交互资产
- 用可微渲染做反向优化（材质估算、姿态、重光照）
- NeRF/GS 的输出再通过提取网格、BRDF 分解接回 PBR 管线

> 严格说 3DGS 不是“回归传统光栅化”，而是 **splatting + alpha 混合的可微近似**；它借了光栅化的速度，没接回 BRDF 的物理语义。

# mlp隐式场是啥？splatting是指投影到2d高斯椭圆的过程吗？可微是什么？指的啥可微？
我拆成三个问题，按“最容易懂的顺序”来：先讲**可微**，再讲**MLP隐式场**，最后讲**splatting**。因为理解了“可微”之后，后两个就顺了。

---

## 1. 可微到底是指什么可微？

**“可微”不是指场景变成了某种特殊东西，而是指“渲染数学公式”可以求导。**

物理学中渲染是一个函数：

```
输入参数 θ（三维坐标、相机内外参、材质/密度等）
            ↓ 执行数学公式
输出图像 I（一张2D像素图）
```

用数学表示就是：

```
I = Render(θ)
```

如果这个公式里处处是连续、光滑的函数（比如加法、乘法、指数、sigmoid），那么就可以算出：

```
∂I / ∂θ = ?
```

也就是：**改变一点点输入的坐标/密度/颜色，图像会改变多少？**

“可微渲染器”意味着：你可以把“像素颜色差”通过链式法则倒着传回去（反向传播），算出应该把每个参数调整多少。

### 举例感受一下：

传统光栅化判断“像素点落在三角形内部吗？”

答案是 0 或 1，硬生生地切一刀。

你问 ∂I/∂x（图像对三角形顶点位置求导）——这个导数在这个硬判断上直接归零，断了。

而 Soft Rasterizer 或 3DGS 的渲染：

```
像素颜色 = Σ (权重_i × 颜色_i)
```

权重不是 0 或 1，而是随深度连续变化的数值（比如 0.82、0.17、0.01）。这时你对位置求导就有非零梯度了，就可以去优化顶点位置或高斯中心。

所以“可微”是指：**把传统的硬离散步骤（遮挡、归属）替换成加权平均的软步骤，让梯度能流过去。**

---

## 2. MLP 隐式场是什么？

拆开三个词：

- **MLP**：多层感知机，就是一个普通的神经网络（输入 a，经过层与层之间的矩阵乘法和非线性激活，输出 b）。
- **场**：数学里的“场”。指“空间里每个点都有一个值”。例如：温度场（每个坐标✈️有温度）、电磁场。
- **隐式**：相对于“显式”说的。

### 显式 vs 隐式

- **显式表示**：一个三角形网格，你把它存成顶点数组+索引数组。里面明确写了一万个顶点坐标在哪。
- **隐式表示**：我不写顶点列表，我只定义一个函数 f(x,y,z)。你问这个函数空间里任意一点 (1,2,3) 是什么，它告诉你“这是个表面”。你问 (1,2,4)，它告诉你“这是虚空”。

> 关键在于：显式是“把面存在数组里”；隐式是“把面存在规则里”。

### NeRF 的 MLP 场长什么样？

NeRF 里，MLP 的输入和输出是：

```
输入：(x, y, z, θ, φ)     【空间位置 + 观察视角】
MLP 变换
输出：(r, g, b, σ)        【颜色RGB + 密度】
```

这个 MLP 本质上定义了一个巨大的连续函数：**你给它任何一个3D坐标，它立刻告诉你这个坐标有多“实心”（密度σ）以及应该是什么颜色（RGB）。**

所以整个场景（一栋房子、一个物体）都被“压缩”进了这个网络参数的权重里。你不需要存几百万个顶点，只需要存几万个网络权重参数。

它“隐”在哪里？**隐在“表面”方程不显式存在，而是藏在密度函数的急剧变化处。** 当你沿着射线采样，发现密度 σ 突然从 0 跳到 1，你就知道这里有个表面了。

缺点也在这里：没有显式的顶点，你没法直接抓手柄去拖拽它，也没法直接导入游戏引擎。需要额外步骤（Marching Cubes）把密度场重提取成网格。

---

## 3. Splatting 是指投影到2D高斯椭圆吗？

**既对也对，但只说了一半。更准确说：Splatting 是“把3D空间里的模糊圆点，甩到屏幕上，变成一片一片的模糊椭圆色块，再按远近叠加在一起”的整个过程。**

拆解 3DGS 渲染的高斯平铺步骤：

**第1步：投影**
是的，就是你说的。每个3D高斯是一个发光的“云团”（数学上是一个钟形分布，有中心和向各个方向膨胀的程度）。渲染时，把这个云团从3D挤到屏幕上：变成屏幕上的一个2D椭圆（高斯分布）。

**第2步：裁剪与排序**
这个2D椭圆的颜色是有透明度的（中心浓，边缘淡）。GPU 把它切碎成一个个像素块（tile）。然后所有图上像素块的高斯椭圆，按照离相机最近的在前，最远的在后，排好队。

**第3步：铺色（Splatting，即“泼溅/落色”）**
从近到远，把这些椭圆一个接一个“泼”在像素上，用透明混合公式一层层叠起来：

```
C_frame = (1 - α_new) × C_old + α_new × C_new
```

就像把颜料一层层地泼到画布上，近的覆盖远的，最后得到这张图。

### 为什么叫 “Splat”（泼溅）？
因为传统光栅化是“先把网格画成多边形，再填色”；而这里 CPU/GPU 不画三角形，是直接拿一堆二维椭圆“丢”到屏幕上，像喷漆或泼水——所以就管这个动作叫 **Splatting**。

**投影只是手段，泼颜色、做混合才是目的。** 整个步骤必须是可微的：投影矩阵要可导、alpha 混合要可导，这样监督信号才能从最终图片传到高斯中心的坐标、尺度、颜色上。

---

## 串联一下整个逻辑

- **可微**：给了我们“方程→梯度→反传→优化”的能力，是地基。
- **NeRF（MLP隐式场）**：在可微渲染框架下，把场景压缩成一个连续函数，任何人都能随时问你“这个坐标离表面多近？”，质量高，但太慢。
- **3DGS（高斯泼溅）**：不搞 MLP 隐式了，把场景拆成一万个显式的小高斯“云团”，保持整个泼溅过程可微，既继承了体渲染/软混合的连续性，又借了 GPU 并行光栅管线的快速度，所以训练快、渲染能实时。

一句话总结关系：
> **可微是底座；NeRF 把“描述场景的规则”塞进网络权重里；3DGS 把“描述场景的规则”改成了一个个参数化的小云团，并沿用了可微的泼溅公式来优化它们。**


# 为什么像素点落在三角形内部吗？导数是0？不应该不存在吗？
你的直觉是对的：**严格说，那个跳变点处的导数不是 0，而是“不存在”**。

之前说“归零”是为了描述最终对优化没帮助的结果，但不精确。下面把它讲清楚。

---

### 1. 覆盖判定是个阶跃函数

假设三角形顶点位置是 `v`，某个像素中心在 `p`。

光栅化器判断：

```
I(p, v) = 1  如果 p 在三角形内部
I(p, v) = 0  如果 p 在三角形外部
```

这个函数对 `v` 的图像，是一个**阶梯函数**：

```
I
1 |______
0 |      |______
  ─────────────────
        v 增大 →
```

- 在每一段“平”的地方（比如 p 明确在内部，或者明确在外部），`I` 不随 `v` 改变，所以**导数为 0**。
- 在 p 恰好划过三角形边界的那个点，`I` 从 0 跳到 1，这里**导数不存在**，不是 0。

所以你的说法更正确：边界点不可导，而不是导数为 0。

---

### 2. 那为什么优化时通常说“梯度断了/梯度为 0”？

因为实际采样中，一个像素点**恰好落在三角形边界上的概率是 0**。

对任意一个具体的像素：

- 它要么在三角形内部，`I=1`，移动一点顶点它还是 1，梯度 = 0；
- 它要么在外部，`I=0`，移动一点顶点它还是 0，梯度 = 0。

边界不可导，但那个不可导点你永远碰不到。所以在数值上你拿到的梯度几乎处处是 **0**。

即使你强行定义一个“跨过边界时梯度无穷大”的广义导数（数学上可以写成狄拉克 δ 函数），深度学习框架的反向传播也没法用它来更新参数——它不是一个可靠的、有方向的梯度信号。

于是最终效果就是：

> 你移动顶点一点点，图像完全不变；梯度算出来是 0；顶点得不到更新信息。

---

### 3. 可微渲染是怎么解决这个问题的？

关键是不要把 `I` 做成硬性的 0/1，而是做成一个连续函数：

```
软覆盖权重 = sigmoid(像素到边的距离 / 平滑参数)
```

当三角形边缘靠近像素时，这个权重连续地从 0 变到 1。

于是像素对顶点位置的导数就变成了一个非零的、平滑的数值：

```
∂权重 / ∂顶点位置 ≠ 0
```

这样梯度才能流过去，顶点才知道“往哪边移动能让这个像素从边缘外变成边缘内”。

---

### 4. 一个简单类比

传统光栅化的覆盖判定就像“门开了没”：开=1，关=0。你轻轻推门，门没开，状态没变化，梯度=0；门开到临界点那一刻状态突然变化，但那个瞬间你是说不清“开了多少”的（不可导）。

可微渲染把门换成“推拉门”：门的位置是连续的，遮住的面积随位置平滑变化。你轻轻推一点，遮住面积就变一点，梯度就有值了。

---

所以更准确的说法是：

> 覆盖判定在连续区间的导数是 0，在边界点不可导。因为不可导点几乎不会被采样到，所以数值上所有像素的梯度都表现为 0，导致反向传播断掉。可微渲染做的事情，就是把这个阶跃改成连续过渡，让边界附近的像素也能产生平滑梯度。


# mlp数学上是不是就是一层层的多维矩阵，矩阵的元素是实数？反向传播是啥？loss又是啥？深度学习的基本概念 原理
问的这几个词正好构成深度学习的骨架：模型、目标、优化。下面从零搭起来。

---

## 1. 总框架：深度学习在干嘛？

一句话：**找一个函数 f，让它的输出尽量接近你想要的结果。**

- 输入：比如一张图片的像素
- 输出：比如“猫”或“狗”的概率
- f：一个多层神经网络

那怎么找这个函数？三步循环：

```
给定一批数据
→ 用当前的 f 算预测，和真实答案比较，得到“错得多离谱”的数值
→ 根据这个数值，调整 f 里面的参数，让下次错得少一点
→ 重复
```

这三步对应的三个概念就是：

- 模型：MLP（多层感知机）
- 错得多离谱的数值：Loss
- 调整参数的方法：反向传播 + 梯度下降

---

## 2. MLP 数学上到底是不是“一层层多维矩阵”？

**是，但少了一个关键部分：非线性激活函数。**

### 一层的内容

MLP 的每一“层”实际上做两件事：

```
第一步：线性变换（就是你说的矩阵乘法）
h = W x + b

第二步：非线性激活
a = σ(h)
```

其中：

- `x`：输入向量，比如一个 784 维的向量（28×28 图片展平）
- `W`：权重矩阵，形状 [输出维度, 输入维度]，矩阵里每个元素都是实数
- `b`：偏置向量
- `σ`：激活函数，比如 ReLU：max(0, x)，或 sigmoid：1/(1+e^(-x))

### 为什么必须要有非线性？

如果只有 `W x + b` 这一套，那么不管堆多少层，最终还是一个线性函数：

```
W₂ (W₁ x + b₁) + b₂ = (W₂W₁) x + (W₂b₁ + b₂)
```

括号里合并起来又是一个矩阵和向量。**堆再深也跟一层没区别。**

只有中间插入 σ，整个函数才不再是线性的，网络才有能力拟合复杂曲线/图像/声音。

### 所以 MLP 的完整数学形式

一个 3 层 MLP 就是：

```
h1 = σ₁(W₁ x + b₁)
h2 = σ₂(W₂ h1 + b₂)
y  = W₃ h2 + b₃
```

所有可学习的参数就是：**一堆矩阵 W₁ W₂ W₃ 和向量 b₁ b₂ b₃**。训练的目标就是找到让 output 最准的那一组矩阵元素。

---

## 3. Loss：怎么衡量“错得多离谱”？

网络输出是预测，数据里存着真实答案。Loss 就是把两者之差压成一个**标量数字**。

### 回归任务（预测数值）
最常用 **MSE（均方误差）**：

```
L = 平均( (预测 - 真实)² )
```

### 分类任务（比如猫狗）
网络输出每个类别的概率，比如 [0.8 猫，0.2 狗]。
真实答案用 one-hot：猫 = [1, 0]。

交叉熵做比较：

```
L = -Σ 真实值_i × log(预测值_i)
```

- 若真实是“猫”，且预测猫概率是 0.8，则 L = -log(0.8) ≈ 0.22
- 若预测猫概率只有 0.01，则 L = -log(0.01) ≈ 4.6

**错得越离谱，L 值越大。Loss 是一个全体参数相关的标量函数：**

```
L = L(W₁, b₁, W₂, b₂, ...)
```

训练目标就是：找到一组参数让 L 最小。

---

## 4. 反向传播：怎么算梯度？

有了 L，下一步要回答一个问题：

> 某个矩阵里的某个元素改变了一点点，L 会变多少？

这个“变化率”就是数学里的偏导数：

```
∂L / ∂W₁[3,5]
```

如果想知道所有参数各自的偏导数，逐个枚举参数、用数值差分去算，参数一多就不现实（几千万甚至上亿个参数）。反向传播是**一次性高效算出所有参数梯度**的算法。

### 核心思想：链式法则

拿最简单的网络：

```
输入 x → z = w·x + b → a = σ(z) → L = (a - y)²
```

我们想知道：`∂L / ∂w = ?`

链式法则一层一层拆：

```
∂L/∂w = ∂L/∂a × ∂a/∂z × ∂z/∂w
```

三个导数都能写出来：

- ∂L/∂a = 2(a - y)【loss对输出的导数】
- ∂a/∂z = σ'(z)【激活函数对线性结果的导数】
- ∂z/∂w = x【线性变换对权重的导数】

然后乘起来就行。

### 为什么叫“反向”？

因为计算顺序是从后往前：

```
先算 ∂L/∂a（输出层的导数）
→ 再算 ∂a/∂z（本层内部）
→ 再算 ∂z/∂w、∂z/∂x（传回输入）
```

每一层的误差信号，从最后一层一层传回第一层。所以叫**Backpropagation**。

反向传播的两种写法：

- **Autograd / 自动微分**：把每个操作记录成一个计算图，系统自动沿图反向算梯度
- **手写解析式**：每个层实现自己的 `backward` 函数

现代深度学习框架（PyTorch、TensorFlow）做的是前者：**你只要写出正向计算，它自动帮你反向求梯度。**

---

## 5. 梯度下降：拿到梯度后怎么更新？

有了梯度，更新规则很简单：

```
新参数 = 旧参数 - 学习率 × 梯度
```

写出来：

```
W ← W - η × ∂L/∂W
```

直观理解：

- 梯度是“L 上升最快的方向”
- 我们想让它下降，所以往反方向走
- η（学习率）是步子大小：太大了震荡，太小了太慢

训练就在反复执行：

```
前向：算预测 → 算 Loss
反向：算每个参数的梯度
更新：参数沿梯度反方向挪一步
```

---

## 6. 用一个小例子完整走一遍

设网络只有一个参数 w，任务是把输入 1 映射成输出 2：

```
预测 ŷ = w × 1 = w
真实 y = 2
Loss L = (ŷ - y)² = (w - 2)²
```

梯度：

```
dL/dw = 2(w - 2)
```

初始假设 w = 0，学习率 η = 0.1：

| 步骤 | w | L | dL/dw | 更新后 w |
|---|---|---|---|---|
| 1 | 0 | 4 | -4 | 0.4 |
| 2 | 0.4 | 2.56 | -3.2 | 0.72 |
| 3 | 0.72 | 1.64 | -2.56 | 0.976 |
| ... | ... | ... | ... | → 2 |

可以看到：w 一步一步逼近 2，Loss 一路下降。

真实应用就是把 w 换成几千万个矩阵参数，Loss 是图片/文本/视频任务上的复杂函数，反向传播在计算图上一层层传梯度。原理完全一致。

---

## 7. 一句话总结四个概念

- **MLP**：一串矩阵乘法 + 非线性激活函数，最终是一个参数化的函数 f(x)
- **Loss**：一个标量，衡量“当前这组参数对应的预测和真实答案差多远”
- **反向传播**：用链式法则高效算出“每个参数对 Loss 的梯度”的算法
- **梯度下降**：拿着梯度把参数往 Loss 下降方向一点点挪

所以完整循环就是：

```
MLP 前向算预测 → Loss 算差距 → 反向传播算梯度 → 梯度下降更新参数 → 再来一次
```

这就是深度学习最核心的骨架。你之前问的“可微渲染”也正是建立在同一套机制上的：渲染方程作为“前向”，照片像素差作为 Loss，渲染器里的可微模块负责“反向传播”，从而优化几何和材质参数。

# 预测 回归  分类 逻辑 这些不同的任务都有啥 都是啥？
这组概念里，“预测”是最大的伞，“回归”和“分类”是伞下的两大任务，“逻辑”则是一个总被名字误导的经典模型。下面按“输入→输出长什么样→怎么定Loss→网络最后一层怎么设计”这条线来讲。

---

## 1. 预测：最上层的总称

任何用已知信息推断未知信息的过程，都叫预测。

超市里：
- 已知“过去的销量 + 季节 + 天气”，预测“明天的销量”。→ 预测
- 已知“顾客的年龄 + 消费记录”，判断“他会不会买会员”。→ 也是预测

**机器学习里的“预测”，绝大多数指的是监督学习：**

```
输入特征 X（车牌图片、传感器读数、文本）
        ↓ 模型 f
输出目标 Y（类别或数值）
```

接下来所有任务的区别，全在看 **Y 是什么类型**。

---

## 2. 回归：预测连续数值

**定义：目标是连续的、有大小顺序的数。**

常见例子：
- 预测房价：89.5 万、210.3 万
- 预测温度：26.5°C
- 预测某视频的播放量：12000 次

### 数学割法

输出是一个实数（或实数向量）：

```
y ∈ ℝ
```

网络最后一层的设计：
- 不做任何特殊处理，直接输出一个数字：线性层 `y = Wx + b`
- 输出范围可以是任意实数

Loss 的选择：
- 最常用 **MSE（均方误差）**：`L = (预测 - 真实)²`
- 或者 **MAE（平均绝对误差）**：`L = |预测 - 真实|`

特点：不仅分数要靠近，连**具体的数值大小**都必须逼真。差 10 万的预测会被严格惩罚。

---

## 3. 分类：预测离散类别

**定义：目标是有限个离散标签，没有大小关系。**

常见例子：
- 猫 / 狗 / 鸟（三分类）
- 手写数字 0-9（十分类）
- 垃圾邮件 / 正常邮件（二分类）

### 数学割法

输出是一个**概率分布**：

```
y ∈ {类别1, 类别2, ..., 类别K}
```

网络最后一层的设计：
- 先把每个类别算出一个得分：`z = Wx + b`，z 是一个 K 维向量
- 再经过 **Softmax** 函数，把所有得分换成“和为1的概率”：

```
p_i = e^{z_i} / Σ e^{z_j}
```

比如得分是 [3.5, 1.2, 0.8]，Softmax 后变成 [0.68, 0.19, 0.13]——含义是“有68%概率属于类别1”。

Loss 的选择：
- 几乎标配 **交叉熵（Cross Entropy）**：`L = -log(p_真实类别)`
- 若真实是猫，且模型给猫的概率是 0.95，则 L = -log(0.95)，很小
- 若模型给猫的概率只有 0.01，则 L = -log(0.01)，很大

特点：**不要求数字精确，只要求概率排序和可信度正确**。预测成“猫的概率0.93”和“猫的概率0.88”都算对。

---

## 4. 分类的三种子类型

| 类型 | 例子 | 输出层设计 |
|---|---|---|
| 二分类 | 是/否、真/假、垃圾/正常 | 单个 sigmoid 输出，范围 0-1，>0.5 算正类 |
| 多分类 | MNIST（0-9）、物种识别 | Softmax，输出 K 维概率，取最大的当预测 |
| 多标签 | 一张图里“有人+有汽车+有树” | 多个独立 sigmoid，每个标签独立判断“有/没有” |

其中 **多分类** 与 **多标签** 容易混淆：
- 多分类：选且只能选一个（如“这是1还是7”）
- 多标签：可以同时选多个（如“图里同时有猫和狗”）

---

## 5. “逻辑”到底是指啥？

在深度学习语境里，“逻辑”通常指 **Logistic Regression（逻辑回归）**。

### 它名字是个陷阱

它名字带“回归”，但它**是一个分类器**。历史原因是它起源于统计学，用来建模“某事件发生的概率”，但现代用法里几乎全拿它做二分类。

### 它的构造

只是在线性模型外面套了一层 sigmoid：

```
z = w·x + b           （和线性回归一样）
p = 1 / (1 + e^{-z})  （压到 0~1 之间，表示概率）
```

- 线性回归：y = w·x + b，输出任意实数
- 逻辑回归：p = sigmoid(w·x + b)，输出 0~1 的概率，然后“若概率 > 0.5 判为类别1，否则类别0”

它是最基础的分类模型：**线性分类器**。

如果你在一个神经网络里看到最后的输出是 sigmoid，那本质就是一个“多层特征提取 + 最后一层逻辑回归”。

| 任务类型 | 你预测的是 | 输出层 | Loss 工具 | 例子 |
|---|---|---|---|---|
| 回归 | 连续数字 | 线性层（任意实数） | MSE / MAE | 房价、温度、播放量 |
| 二分类 | 两个标签之一 | Sigmoid（0~1概率） | 交叉熵 | 垃圾邮件、患病与否 |
| 多分类 | K个标签之一 | Softmax（总和为1） | 交叉熵 | 手写数字 0-9 |
| 多标签 | 同时多个标签 | 多个 Sigmoid | 各自交叉熵求和 | 图片多物体识别 |
