# 噪声的数学基础及工程实现基础
图形学中“噪声”是一类程序化生成的随机信号，用于模拟自然纹理、地形、云朵等。它们的数学基础并不是单一的，但也不是毫无关联。

## Hash 函数是数学基础吗？

不是。Hash 函数在噪声算法中主要扮演“伪随机数生成器”的角色，用来把空间坐标映射成确定性的随机值或随机梯度。它属于工程实现工具，而不是底层数学理论。没有了 hash，噪声算法依然可以用预计算的随机表或真实随机数实现；只是 hash 让程序化噪声更简洁、无需存储海量数据。

## 常见噪声的数学基础

**白噪声**  
每个采样点独立同分布随机变量，没有空间相关性。功率谱平坦，是随机过程的最基础形式。

**值噪声 Value Noise**  
把空间划分成晶格，在每个格点生成一个随机值，然后用平滑插值（如 smoothstep）填充格点之间。数学基础是“采样 + 低通滤波插值”。

**Perlin 噪声**  
在晶格顶点生成随机梯度向量，用梯度和采样点到顶点的方向向量做点积，再插值加权。数学基础是晶格、随机向量场和高阶插值，目的是让噪声在格点处梯度连续，视觉上更自然。

**Simplex 噪声**  
改进了 Perlin 噪声。使用单纯形剖分空间，并通过偏斜坐标变换让采样点只对邻近的少数顶点做贡献。数学基础是单纯形、仿射变换和对称性分析，解决了 Perlin 噪声的计算复杂度和方向性伪影。

**Worley 噪声（细胞噪声）**  
在空间中随机撒点（晶格中每格随机放一个特征点），然后计算任意位置到最近几个特征点的距离。数学基础是 Voronoi 图 / 距离变换。它生成的图案像细胞或岩石纹理。

**分形噪声（FBM）**  
把不同频率、不同振幅的噪声叠加起来，形成自相似的分形信号。数学基础是分形几何和尺度不变性。常用于地形、云层和火焰效果。

## 有没有统一的数学基础？

严格地说，没有“同一个数学基础”。但可以把所有程序化噪声放在一个共同框架里理解：

**空间随机场**：所有噪声都是定义在空间上的随机场，即一组随机变量随空间位置变化。

**频域分析**：不同噪声的本质差异体现在功率谱密度上。白噪声频谱平坦；Perlin 类噪声通常是带通或低通的，能量集中在有限频率范围内。这也决定了噪声的“粗细”和自然程度。

**构造范式**：绝大多数程序化噪声都遵循：

1. 把空间划分成规则网格（晶格、单纯形、细胞）；
2. 在每个格点或特征点定义随机属性（值、梯度、位置）；
3. 用插值、点积或距离函数把这些属性扩展到连续空间；
4. 在频域上形成平滑的带通特性，获得可调的自然表现。

所以，hash 函数只是实现中用来产生随机属性的手段，而真正的数学基础是“随机场 + 空间离散化 + 滤波/插值 + 分形叠加”。它们没有统一的定理，但有统一的设计思想。

# 柏林噪声通过2d纹理坐标映射到vec2，认为这个值是梯度，还是这个值数学上真的是梯度？为啥又跟格点的距离点乘？最后的双线性插值我理解是为了平滑，是不是？
三个问题都问到点子上了，逐个说。

## 一、是真的梯度，不是"当成"梯度

Perlin 噪声本质上是 **Hermite 插值**：构造一个标量场 `n(p)`，使得在每个整数格点 `c` 上

```
n(c) = 0,    ∇n(c) = g_c
```

`g_c` 就是那个随机 vec2。它是货真价实的空间梯度，不是比喻。

为什么成立？看单个角点的贡献 `dot(g, d)`，其中 `d = p - c`。这是 `g·d` 的线性项，恰好是泰勒展开的一阶项：在 `d=0` 处值为 0，而对 `p` 求导就是 `g`（因为 `g` 是常向量）。所以它天然满足"格点处值为 0、梯度为 g"。

对比一下**值噪声（value noise）**：它在格点上随机赋一个标量值再插值，格点值非 0。Perlin 反过来——格点值恒为 0，随机的是梯度。这就是"梯度噪声"名字的由来。

## 二、为什么点乘距离

点积就是投影，几何含义很直接：

- 位移 `d` 与梯度 `g` 同向 → 贡献最大
- 垂直 → 贡献为 0
- 反向 → 负值

数学上它同时满足两个约束：`d=0` 时值为 0（保证格点连续、格点值为 0），`∂(g·d)/∂p = g`（保证梯度性质）。换成别的组合（比如直接取 `g.x * d.x`）就破坏不了第一个也保不住第二个。

顺便一个常见 bug：四个角的位移向量不一样。

```
n00 = dot(g00, ( fx,      fy     ))
n10 = dot(g10, ( fx - 1,  fy     ))
n01 = dot(g01, ( fx,      fy - 1 ))
n11 = dot(g11, ( fx - 1,  fy - 1 ))
```

`n10` 的位移是 `p - (x0+1, y0)`，不是 `(fx, fy)`。写错这个，噪声会整体偏移、出现方向性伪影。

## 三、插值：是平滑，但比"平滑"更硬的要求

结构上确实是"先 x 后 y"的**双线性混合**（bilinear blend），但权重函数不是线性的，而是 **fade 曲线**：

```
1985 版：3t² - 2t³              → C1 连续
2002 版：6t⁵ - 15t⁴ + 10t³      → C2 连续
```

用它的原因有两层：

**1. 消接缝（你理解的那层）**
普通线性插值只有 C0 连续，导数在格线处突变，渲染出来能看到明显的网格状折痕。fade 曲线在端点导数满足 `w'(0) = w'(1) = 0`，于是跨格线的一阶导连续，接缝消失。2002 版连二阶导也归零，高光/法线扰动下更干净。

**2. 保证"格点梯度 = g"这个性质（容易被忽略的一层）**

回到 `n(p) = Σ w_i(x) w_j(y) · dot(g_ij, d_ij)`。在格点 `c_kl` 求梯度：

```
∇n = g_kl + (含 ∇w 的项)
```

只有当 `∇w` 在格点处为 0 时，后面那项才消失，才有 `∇n(c_kl) = g_kl`。fade 曲线正好满足这一点；**换成线性权重 `w=t`，`w'≡1`，格点梯度就不再等于 `g`**，整个"梯度噪声"的定义就塌了。

所以 fade 曲线不是可有可无的美化，它和点积是配套的。

## 四、两个附带结论

**格点值恒为 0 的代价**：噪声场在整数格点上全是 0，直方图在 0 处有尖峰，整体对比度偏低、偏灰。这是 Perlin 的已知短板，实际用的时候几乎总要 remap 或者叠 fBm。

**梯度场不是 g 的插值**：`∇n` 在格点等于 `g`，但在格内并不等于 `g` 的双线性插值——`n` 是 Hermite 插值，`∇n` 是它的导数，是另一个（更复杂的）场。所以"格点采样梯度"和"梯度场的插值"别混为一谈。

```python
def fade(t):
    return t*t*t*(t*(t*6 - 15) + 10)

def perlin2(p, grad_at):
    x0, y0 = math.floor(p[0]), math.floor(p[1])
    fx, fy = p[0] - x0, p[1] - y0
    g00 = grad_at(x0,   y0);  g10 = grad_at(x0+1, y0)
    g01 = grad_at(x0, y0+1);  g11 = grad_at(x0+1, y0+1)
    n00 = g00[0]*fx     + g00[1]*fy
    n10 = g10[0]*(fx-1) + g10[1]*fy
    n01 = g01[0]*fx     + g01[1]*(fy-1)
    n11 = g11[0]*(fx-1) + g11[1]*(fy-1)
    u, v = fade(fx), fade(fy)
    return (n00*(1-u) + n10*u)*(1-v) + (n01*(1-u) + n11*u)*v
```

实际实现里 `grad_at` 通常不是真随机，而是哈希到 8 个（2D）或 12 个（3D）方向之一，这样可复现、可并行、无状态。

# Simplex对Berlin噪声的改进
先把结论摆出来：**Simplex 不是“另一种噪声”，而是 Perlin 的晶格重构**——梯度噪声的基本思想（随机梯度 + 距离点乘 + 平滑贡献）没变，变的是“在哪个网格上、用几个点、怎么加权”。

## 一、核心差异一览

| 维度 | Classic Perlin (1985/2002) | Simplex (Perlin 2002) |
|---|---|---|
| 晶格 | 超立方体（2D 正方形 / 3D 立方体） | 单纯形（2D 等边三角形 / 3D 正四面体） |
| 参与顶点数 | 2^N（2D:4, 3D:8, 4D:16） | N+1（2D:3, 3D:4, 4D:5） |
| 复杂度 | O(2^N) | O(N²) 量级 |
| 加权方式 | 距离点乘 + fade 曲线双线性/三线性混合 | 距离点乘 × 径向衰减核，直接求和 |
| 各向同性 | 中等，有 45°/90° 方向性伪影 | 高，伪影几乎不可见 |
| 特征形状 | 偏方形/轴对齐 | 偏圆形/球形 |
| 高维表现 | 3D 还行，4D 开始吃力 | 3D/4D 明显更快更干净 |
| 实现难度 | 简单 | 斜坐标变换 +  simplex 定位，较绕 |

## 二、Perlin 回顾（对照用）

超立方体网格，N 维采样点找 2^N 个角点：

```
d_i = p - corner_i
contrib_i = g_i · d_i          // 梯度投影
n = lerp_over_corners(contrib, fade(t))
```

`fade(t) = 6t⁵ - 15t⁴ + 10t³`，保证 C² 连续。问题根子在“正方形网格”——梯度场天然带轴对齐偏好，高频下会出现方格纹、方向性涟漪。

## 三、Simplex 的关键改造

### 1. 晶格换成单纯形

N 维单纯形是“用最少顶点张成 N 维空间”的多面体：

- 2D：等边三角形（3 顶点）
- 3D：正四面体（4 顶点）
- 4D：5-cell（5 顶点）

顶点数从 2^N 砍到 N+1，这是性能提升的主要来源。

### 2. Skew / Unskew 坐标变换

直接判断“点在哪个三角形里”很麻烦，Simplex 用一个线性变换把菱形网格变成轴对齐网格：

```
skew:   s = (x+y+...) · F_n        F_n = (√n - 1)/n
        x' = x + s
cell:   i = floor(x'), j = floor(y')

unskew: t = (i+j+...) · G_n        G_n = (1 - 1/√n)/n
        corner = (i - t, j - t)
```

2D 常数 `F₂ ≈ 0.366`, `G₂ ≈ 0.211` 。变换后只要比较 `x0 > y0` 就能决定取哪三个顶点，非常 GPU 友好。

### 3. 径向衰减核（不是插值）

这是和 Perlin 最本质的区别——**Simplex 不做双线性混合，而是每个顶点独立贡献、再求和**：

```
r² = |d|²
w = max(0, R² - r²)          // R²=0.5 (2D/3D), 0.6 (4D)
contrib = w⁴ · (g · d)
n = Σ contrib_i
```

`w⁴` 在支撑半径边缘一阶、二阶导都为 0，保证 C²；`w` 是径向对称，所以没有方向偏置 。

### 4. 归一化缩放

求和后乘一个经验系数把输出拉回 `[-1, 1]`：

- 2D：×130
- 3D：×105
- 4D：×49

这些系数是“调出来”的，不是理论推导——因为梯度方向分布 + 衰减核的实际极值很难闭式求出 。

## 四、为什么 Simplex 看起来更“自然”

三个数学原因：

1. **晶格对称度高**：三角形/四面体比正方形旋转对称，方向偏置小。
2. **径向核各向同性**：贡献只依赖到顶点的距离，不依赖方向。
3. **支撑域更紧**：每个点只受最近 N+1 个顶点影响，远处不污染，高频细节更干净。

Perlin 的“方块感”在高频率、多倍频 fBm 下会被放大；Simplex 在同样倍频下视觉更柔和。

## 五、代价与坑

**实现复杂度**：skew 变换、simplex 定位、梯度哈希都比 Perlin 绕。直接抄 Ashima / Gustavson 的 GLSL 实现比自己写靠谱。

**归一化不是精确的**：不同实现（2D/3D/4D、OpenSimplex、SuperSimplex）缩放系数不同，跨实现拼采样会得到不一致的值域，务必各自归一化再混合。

**2D 下 Perlin 不一定更慢**：2D Perlin 只算 4 个点，现代 CPU/GPU 上和 Simplex 的 3 个点差距很小，甚至 Perlin 因实现简单更快。Simplex 的优势在 **3D 及以上**。

**专利历史**：Simplex 原专利 2022 年已到期，现在可自由使用，不用担心授权 。

**SuperSimplex / OpenSimplex2**：进一步把 2D 采样点扩到 4 个、3D 到 8 个，换取更平滑、更圆的特征，代价是更慢。需要“极致柔和”时用。

## 六、工程选型

- **2D 地形/纹理**：两者都行。要简单可预测 → Perlin；要少方向伪影 → Simplex。
- **3D 体积云/雾/体渲染**：Simplex 明显更优（8→4 个角点）。
- **4D 时空动画**（x,y,z + time）：Simplex 几乎是唯一现实选择（16→5）。
- **需要无缝平铺（tiling）**：Perlin 的周期性好做；Simplex 要做周期版得用 psrdnoise 或手动折叠坐标。
- **需要解析梯度**（法线扰动、domain warp）：选带 `out grad` 的 Simplex 实现，一次采样同时拿值和导数。
- **快速原型/低质量**：Value noise 更快，但块状感重。

## 七、和前面讨论的衔接

- Perlin 的 fade 曲线 = Hermite 值基函数；Simplex 完全抛弃了“插值”这一步，改用**径向基函数（RBF）求和**，思想上更接近薄板样条/TPS 的“局部核叠加”。
- fBm、turbulence、ridged 这些后处理对两者通用，倍频调度一样。
- Domain warping 时 Simplex 的解析梯度质量更好，flow noise / curl noise 通常用 Simplex 打底。

一句话：**Perlin 是“在方格里插值”，Simplex 是“在三角网格上做径向核叠加”**——目标相同，路径不同，高维和高质量场景 Simplex 胜出，2D 简单场景 Perlin 依然够用。

# fbm是啥？分形是啥？纹理噪声里的fbm又是啥
## 一、三个词的关系

一句话：**分形是几何性质，布朗运动是随机过程，fBm 是“带记忆的布朗运动”，纹理里的 fBm 是用多倍频噪声去逼近 fBm 的功率谱。**

三者的关系是：

```
分形（自相似、非整数维）
  └─ 布朗运动（H=0.5 的特例）
       └─ 分数布朗运动 fBm（H 可调）
            └─ 纹理 fBm（用噪声叠加近似其频谱）
```

## 二、分形

**英文 fractal**，Mandelbrot 1975 年造的词，源自拉丁语 *fractus*（破碎）。

数学上没有唯一公理化定义，通行的刻画是**自相似性**：

```
S(λ·x) ≈ λ^H · S(x)      统计意义上的自相似
```

关键性质是 **Hausdorff 维数严格大于拓扑维数**。对曲线 `D ∈ (1,2)`，对曲面 `D ∈ (2,3)`。

两类：

- **确定性分形**：Koch 雪花、Sierpinski 三角形、Mandelbrot 集——严格自相似，可无限放大
- **统计分形**：海岸线、云、地形、股票曲线——只在统计意义上自相似，放大后“看起来像”

纹理噪声属于后者。

## 三、从布朗运动到 fBm

**布朗运动** `B(t)`：独立平稳增量的随机过程，`B(t) - B(s) ~ N(0, |t-s|)`。注意方差正比于时间间隔，这是它“处处不可微、无限粗糙”的根源。

**分数布朗运动**（fractional Brownian motion, fBm），Mandelbrot & van Ness 1968：

```
E[|B_H(t) - B_H(s)|²] = σ² · |t - s|^{2H}
```

`H ∈ (0,1)` 是 **Hurst 指数**，控制“粗糙度”：

| H | 行为 | 视觉 |
|---|---|---|
| → 0 | 增量剧烈反相关，极粗糙 | 尖刺、砂砾 |
| 0.5 | 退化为普通布朗运动 | 中性 |
| → 1 | 增量正相关，极光滑 | 缓坡、大块 |

**功率谱**（关键）：

```
S(f) ∝ f^{-β},    β = 2H + n     （n 为维数）
```

一维时 `β = 2H + 1`，二维时 `β = 2H + 2`。这是 `1/f` 噪声族的推广——`β=0` 白噪声，`β=2` 粉红/布朗，`β` 越大越低频。

**分形维数**：`D = n + 1 - H`。二维图像 `D = 3 - H ∈ (2,3)`。`H=0.5` 对应 `D=2.5`，是最常见的“自然纹理”档位。

## 四、纹理里的 fBm

计算机里没法直接采样连续 fBm（非平稳、非高斯、不可微），工程做法是**多倍频叠加**（octave summation）：

```
fbm(p) = Σ_{i=0}^{N-1} gain^i · noise(lacunarity^i · p)
```

四个参数：

| 参数 | 含义 | 常用值 |
|---|---|---|
| `octaves` | 叠加层数 | 4~8 |
| `lacunarity` | 频率倍增因子 | 2.0（也可 1.9~2.3） |
| `gain` / `persistence` | 振幅衰减因子 | 0.5 |
| `noise` | 底层噪声 | Perlin / Simplex / Value |

`gain = 0.5, lacunarity = 2` 是黄金组合：每层频率翻倍、振幅减半。

**谱指数关系**（能对上理论的关键）：

```
β = -2·log(gain) / log(lacunarity)
```

`gain=0.5, lac=2` → `β = 2`。二维下 `β = 2H + 2` 反推 `H = 0`……注意这里**不要硬套公式**：纹理 fBm 的谱只在 octave 覆盖的频段内近似 `f^{-β}`，而且底层噪声本身不是白噪声（Perlin 自带 `f^{-2}` 量级的谱包络），所以实际有效 `β` 更高。经验上 `gain=0.5, lac=2` 加 Perlin 底层，视觉上接近 `H ≈ 0.7~0.9`，这正好落在“自然”区间。

**为什么必须归一化**：

```
fbm(p) = Σ a_i·n_i / Σ a_i,    a_i = gain^i
```

不除 `Σ a_i`，输出会随 octaves 线性增长，超出 `[0,1]` 后截断，直方图变成双峰。

## 五、为什么它“不严格是 fBm”

四个偏差，都得知道：

1. **分布不是高斯**：fBm 定义要求高斯增量。Perlin 输出分布集中在 0 附近、有界，fBm 叠加后中心极限效应让它*趋近*高斯，但有限 octave 下不是。
2. **非平稳**：Perlin 的格点周期性让统计量随位置微变；真 fBm 增量平稳。
3. **谱只在有限频段**：octave 从 `f_0` 到 `f_0·lac^{N-1}`，两端截断。低于 `f_0` 无能量，高于上界无细节——放大能看到“空”，缩小能看到“糊”。
4. **各向异性残留**：底层 Perlin 的轴对齐伪影会被叠加放大。

所以严格说法是“**分形噪声**（fractal noise）”或“**fBm 近似**”。图形学社区习惯直接叫 fBm，是约定俗成。

## 六、变体

都是同一套 octave 骨架，改的是单层变换：

```
fBm        Σ a_i · n_i                      中性、云、地形
turbulence Σ a_i · |n_i|                    锐利、火焰、水面
billow     Σ a_i · |n_i| 然后 remap         蓬松、棉花、烟
ridged     Σ a_i · (1 - |n_i|)^k            山脊、沟壑（k 控制锐度）
```

`turbulence` 取绝对值会引入 `C⁰` 折点，视觉上产生“丝状”结构，正是火焰需要的。`ridged` 反向折叠，`1-|n|` 在 `n=0` 处取极大，形成脊线。

还有 **domain warping**（域扭曲），不是变体而是复合：

```
q = fbm(p)
r = fbm(p + 4·q)
fbm(p + 4·r)
```

两层扭曲就能做出大理石、木纹、流体感。这是 Inigo Quilez 推广的技巧，性价比极高。

## 七、代码

```python
import math

def fbm(p, octaves=6, lacunarity=2.0, gain=0.5, noise=None):
    total, amp, freq, norm = 0.0, 1.0, 1.0, 0.0
    for _ in range(octaves):
        total += amp * noise(p[0]*freq, p[1]*freq)
        norm  += amp
        amp   *= gain
        freq  *= lacunarity
    return total / norm          # 归一化到 [0,1]

def turbulence(p, **kw):
    total, amp, freq, norm = 0.0, 1.0, 1.0, 0.0
    for _ in range(kw.get('octaves', 6)):
        total += amp * abs(noise(p[0]*freq, p[1]*freq))
        norm  += amp
        amp   *= kw.get('gain', 0.5)
        freq  *= kw.get('lacunarity', 2.0)
    return total / norm

def ridged(p, octaves=6, lacunarity=2.0, gain=0.5, sharp=2.0):
    total, amp, freq, norm = 0.0, 1.0, 1.0, 0.0
    for _ in range(octaves):
        n = 1.0 - abs(noise(p[0]*freq, p[1]*freq))
        total += amp * n**sharp
        norm  += amp
        amp   *= gain
        freq  *= lacunarity
    return total / norm
```

## 八、坑

**1. 走样（aliasing）**
最高频 octave 的周期接近像素间距时，出现摩尔纹和闪烁（动画时尤其明显）。处理：

- 按屏幕导数自适应减少 octaves（`octaves = clamp(log2(1/fwidth), 0, max)`）
- 预滤波：用带限噪声，或对底层噪声做 mipmap 层级平均
- `lacunarity` 用非整数（如 1.93），避免各层谐波在整数频率上叠加放大

**2. 格点对齐**
底层 Perlin 的整数格点周期性，在 `lacunarity` 为整数时会让不同 octave 的格点重合，产生规则斑纹。做法：每层加随机偏移 `noise(freq*p + offset_i)`，或直接换非整数 `lacunarity`。

**3. 归一化方式不统一**
除以 `Σ a_i` 是最小-最大式的保守归一化，实际输出仍可能小幅越界（因为底层噪声理论极值罕见）。要严格 `[0,1]` 就再 clamp，或者用统计归一化（采样估 `μ, σ`）。

**4. octaves 与性能**
`octaves` 线性增加成本。GPU 上 4~6 层通常够；需要更多细节时优先提高分辨率而不是堆 octave。

**5. 无缝平铺**
周期纹理要求每层噪声都在同一周期上平铺，且 `lacunarity` 必须是整数（否则周期不整除）。这是 Perlin 比 Simplex 好做 tiling 的原因。

## 九、和前文的衔接

- 单层 Perlin 的 fade 曲线保证 `C²`，但**格点值为 0** 导致对比度偏低——fBm 叠加正好补上这一点，多层错相位后直方图展宽。
- fBm 本质是**在不同尺度上重复同一个插值/核叠加过程**，和样条的“分段”思想同源：局部低次 + 多尺度组合，避免高次全局振荡。
- Simplex 的径向核各向同性，做 fBm 时方向伪影更少；Perlin 做 fBm 时 45° 方格纹会被累加放大，所以高质量场景优先 Simplex。
- 想要真正严格的 fBm（谱精确、高斯增量），得走**谱合成法**：FFT 白噪声 → 乘 `f^{-β/2}` 幅度谱 → 逆 FFT。这是离线渲染、地形生成里另一条路线，代价是不能任意分辨率采样。

**接下来你想看谱合成法的实现，还是 fBm 在域扭曲/法线扰动里的具体用法？**

# voronoi 垂直平分线 中垂线 delauny三角化是啥？图形学里有哪些应用
先给一张图级别的结论：这四个东西其实是**同一件事的四个侧面**——

- **垂直平分线 / 中垂线**：两个点之间“谁更近”的分界，是 Voronoi 边的**局部几何来源**
- **Voronoi 图**：把所有点按“最近归属”划分，得到一堆多边形细胞
- **Delaunay 三角化**：Voronoi 的对偶图，把相邻细胞的种子点连成三角形
- **二者关系**：同一套点集的“一体两面”，边互相正交

## 一、中垂线 / 垂直平分线

两个点 A、B，平面上“到 A 和到 B 距离相等”的点的集合，就是线段 AB 的**垂直平分线（perpendicular bisector）**。它把平面切成两半：

- 左半：离 A 更近
- 右半：离 B 更近

数学形式：

```
{x : |x-A| = |x-B|}
```

它只是“两个点”的局部分界。多个点时，每个点和其它所有点都画一条中垂线，取“包含自己那一侧”的半平面，再取交集——就得到这个点独占的区域。这就是 Voronoi 细胞的构造原理。

> 💡 注意：中垂线只在**欧氏距离**下是直线。换成曼哈顿距离（L¹），分界变成 45° 折线；换成切比雪夫距离（L∞），变成直角台阶。度量决定了 Voronoi 的形状。

## 二、Voronoi 图

**定义**：给定点集 `P = {p₁,...,pₙ}`，每个点 `pᵢ` 对应一个细胞（cell）

```
V(pᵢ) = { x : |x - pᵢ| ≤ |x - pⱼ|, ∀j ≠ i }
```

也就是“平面上离 pᵢ 最近的所有点”。别名很多：泰森多边形（Thiessen polygon）、Dirichlet 镶嵌。

**几何性质**：

- 每个细胞是凸多边形（欧氏下）
- Voronoi 边 = 相邻两点中垂线的一段
- Voronoi 顶点 = 三条或以上中垂线交汇点 = 到三个种子点等距的点 = 这三个点构成圆的圆心

**Worley 噪声 / Cellular 噪声**：就是 Voronoi 图在着色器里的叫法。像素不去算“属于哪个细胞”，而是算“到最近种子的距离”：

```
F1 = min_i  dist(p, seed_i)          // 到最近点
F2 = 第二近的距离
F2 - F1                              // 边缘检测，画细胞边界
1 - F1                               // 细胞核高亮
```

F1/F2 的组合能做出裂纹、鳞片、泡沫、细胞、水底焦散。

## 三、Delaunay 三角化

**定义**：把点集连成三角形，满足**空外接圆准则（empty circumcircle）**——

> 任意一个三角形的外接圆内，不包含任何其他种子点。

等价于**最大化最小角**：在所有可能的三角化里，Delaunay 让“最瘦的三角形”尽可能胖，避免细长 sliver 三角形。

为什么这个性质这么重要？因为三角形越“正”，插值、有限元、光照、法线计算都越稳定。

**3D 推广**：把三角形换成四面体，空外接圆换成空外接球，就是 3D Delaunay 三角化（tetrahedralization）。

## 四、对偶关系（最关键的一张图）

Voronoi 和 Delaunay 是**对偶图**，一一对应：

| Voronoi 侧 | Delaunay 侧 |
|---|---|
| 种子点（细胞中心） | 顶点 |
| 细胞（面） | 点 |
| 共享边（两个细胞相邻） | 连接这两个种子的边 |
| Voronoi 顶点（三线交汇） | Delaunay 三角形 |
| 中垂线 | 与 Delaunay 边正交 |

几何上还有两个硬性质：

- Delaunay 三角形的**外心** = 对应 Voronoi 顶点
- Delaunay 边与其对偶的 Voronoi 边**互相垂直**

所以算出一个就能推出另一个。工程实现通常先算 Delaunay（用 Bowyer-Watson 增量插入或 Fortune 扫描线，O(n log n)），再从三角形外心反推 Voronoi 细胞。

## 五、图形学应用全景

### 1. 程序化纹理（Shader 层）

- **Worley/Cellular 噪声**：裂纹、鳞片、蛇皮、橘子皮、泡沫、细胞组织
- **F2-F1 边缘**：石头缝隙、干裂大地、冰裂纹
- **多层 Worley + fBm**：云团、岩浆、腐蚀表面
- **焦散（caustics）**：水面折射亮纹，用两层错位的 Worley 叠加模拟

### 2. 程序化地图与地形

- **生物群系划分**：撒点代表生态中心，Voronoi 细胞就是领地，边缘做过渡带
- **双网格（Dual Mesh）**：Delaunay 顶点 = 地形采样点，Voronoi 细胞 = 地块。Amit Patel 的经典多边形地图生成器就是这个思路
- **河流模拟**：在水往低处流的格点上，沿 Voronoi 邻接关系传播
- **高度场分层**：每个细胞独立赋高程、湿度、材质，再用噪声在边界混合，避免硬切

### 3. 破碎与物理

- **碎裂模拟**：在网格内随机撒种子，沿 Voronoi 边界切开，每块变成刚体碎片
- **玻璃裂纹**：冲击点附近密集撒点 + Lloyd 松弛，做出真实的放射状裂纹
- **布料/软体**：用 Delaunay 把粒子连成约束网络，比规则网格更自然、更不易拉伸

### 4. 网格生成与几何处理

- **地形 TIN（不规则三角网）**：Delaunay 三角化点云，得到高质量地形网格
- **有限元前处理**：Delaunay 最大化最小角，数值稳定性最好
- **点云重建 / 表面重建**：3D Delaunay + α-shape 提取物体表面
- **重网格化（remeshing）**：Lloyd 松弛让顶点均匀，再 Delaunay，得到均匀三角网

### 5. 采样与渲染

- **点画渲染（Stippling）**：密度加权 Voronoi（CVT，质心 Voronoi 剖分）把点分布成图像明暗
- **蓝噪声采样**：CVT 迭代产生近似蓝噪声的采样点，比纯随机更均匀，适合光线追踪、SSAA
- **Lloyd 松弛**：反复把种子移到细胞质心，让细胞大小均匀——碎裂、城市群、细胞生长都用它

### 6. AI 与空间查询

- **最近邻搜索**：Voronoi 细胞直接告诉你最近种子是谁，配合 Delaunay 图可 O(log n) 查询
- **导航网格（NavMesh）**：Delaunay 三角网作为可行走区域基础，合并三角形生成寻路网格
- **势力范围 / 领地 AI**：策略游戏里每个基地的“控制区”，移动种子还能做动态领土演变

### 7. 高阶拓展

- **3D Voronoi**：晶体生长、多晶材料、小行星内部构造、洞穴腔体
- **Power Diagram（Laguerre-Voronoi）**：每个种子带权重（半径），细胞大小可调，模拟泡沫、球体堆积
- **Geodesic Voronoi**：在网格表面上按测地距离划分，用于纹理图集、骨骼绑定、表面重网格
- **GPU Cone-based Voronoi**：每个种子画一个锥体，深度缓冲自然选出最近种子，O(n) 实时算法

## 六、常见误区

**1. “Voronoi 边都是线段”**
错。边界可能是线段、射线、甚至无限延伸的线（最外层细胞没有封闭边界）。完整实现要处理射线和开放边。

**2. “Delaunay 就是好看的三角化”**
不够准确。它是**唯一满足空圆准则**的三角化（四点共圆时可能不唯一）。不是“看着舒服”，是数学上被空圆条件完全确定。

**3. “中垂线直接就是 Voronoi 边”**
只对相邻点对成立。两个不相邻的点虽然也有中垂线，但那段线可能被其它细胞挡掉，根本不出现在最终图里。

**4. “Worley 噪声 = Voronoi 图”**
Worley 噪声是 Voronoi 的**距离场应用**，不是图本身。它不输出“属于哪个细胞”，只输出“到最近/第 k 近种子的距离”。

**5. 高维爆炸**
Voronoi 在 2D/3D 很实用，但 d≥4 时复杂度指数级上升，实际用近似（kd-tree、HNSW）代替。

## 七、和你前面噪声体系的衔接

把这几层叠起来看，程序化纹理的工具箱就完整了：

```
Perlin/Simplex   → 连续平滑的大尺度形变（地形起伏、云雾）
fBm             → 多尺度叠加，自相似细节
Worley/Voronoi  → 不连续的细胞结构（裂纹、鳞片、气泡）
Delaunay        → 把特征点连成网格（地形、破碎、NavMesh）
```

实际工程里经常混用：用 Voronoi 划生物群系边界，用 fBm 在边界做材质混合，用 Delaunay 生成可行走网格，用 Worley 做石头表面裂纹。四者不是替代关系，是不同尺度的分工。

**接下来想先看 Worley 噪声的 GLSL 实现，还是 Delaunay 三角化的工程实现思路？**

# 欧氏距离 曼哈顿距离 切比雪夫距离
## 一、统一框架：Lp 范数（Minkowski 距离）

三种距离其实是**同一个公式取不同参数**。对向量 `x = (x₁, ..., xₙ)`：

```
‖x‖_p = ( Σᵢ |xᵢ|^p )^{1/p},    p ≥ 1
d_p(a, b) = ‖a - b‖_p
```

- `p = 1` → 曼哈顿距离
- `p = 2` → 欧氏距离
- `p → ∞` → 切比雪夫距离

之所以能叫“距离”，是因为 `d_p` 满足**度量公理**：

```
1. d(x,y) ≥ 0            非负
2. d(x,y) = 0 ⟺ x = y   同一性
3. d(x,y) = d(y,x)       对称
4. d(x,z) ≤ d(x,y)+d(y,z) 三角不等式
```

第 4 条对 `p ≥ 1` 成立（Minkowski 不等式），**对 `p < 1` 不成立**——所以 `p=0.5` 那种“分数距离”不是度量，只能当相似度用。

## 二、欧氏距离（L2）

```
d₂ = √( (x₁-y₁)² + (x₂-y₂)² + ... )
```

- **别名**：Euclidean distance，`ℓ₂` 距离
- **单位球**：圆 / 球面 / 超球面
- **性质**：旋转不变、各向同性，是物理空间的真实距离
- **代价**：含开方，工程上常比较平方距离 `d²` 避免 `sqrt`（排序、最近邻不受影响）

## 三、曼哈顿距离（L1）

```
d₁ = |x₁-y₁| + |x₂-y₂| + ...
```

- **别名**：taxicab distance、city block distance、rectilinear distance、`ℓ₁`
- **单位球**：**菱形**（旋转 45° 的正方形），2D 顶点在 `(±1,0), (0,±1)`
- **名字来源**：曼哈顿街道网格，只能沿街走，不能斜穿
- **性质**：无开方、纯加减，整数运算友好；对离群值比 L2 不敏感（因为不平方）

**离散版**：在 `{0,1}ⁿ` 上退化为**汉明距离**（不同位的个数），是编码理论、纠错码的基础。

## 四、切比雪夫距离（L∞）

```
d∞ = max( |x₁-y₁|, |x₂-y₂|, ... )
```

- **别名**：Chebyshev distance、chessboard distance、maximum metric、`ℓ∞`
- **单位球**：**正方形**（轴对齐），2D 顶点在 `(±1,±1)`
- **名字来源**：国际象棋里国王走一步，横、竖、斜都算一步，距离就是 `max(|Δx|,|Δy|)`
- **推导**：`lim_{p→∞} (Σ|xi|^p)^{1/p} = max|xi|`，因为最大项压过其余项

## 五、等距轮廓对比

单位圆 `d(x, 0) = 1` 的形状：

| p | 形状 | 2D 单位球 |
|---|---|---|
| 1 | 菱形 | `\|x\|+\|y\| ≤ 1` |
| 1.5 | 圆角菱形 | 超椭圆 |
| 2 | 圆 | `x²+y² ≤ 1` |
| 4 | 圆角方形 | 超椭圆 |
| ∞ | 正方形 | `max(\|x\|,\|y\|) ≤ 1` |

一般 `p` 的形状是**超椭圆**（Lamé 曲线）`|x|^p + |y|^p = 1`。`p` 从 1 增到 ∞，形状从菱形连续“鼓”成正方形，中间经过圆。

## 六、大小关系

对任意向量，**p 越大范数越小**：

```
‖x‖_∞ ≤ ‖x‖₂ ≤ ‖x‖₁
```

具体界（n 维）：

```
‖x‖_∞ ≤ ‖x‖₂ ≤ √n · ‖x‖_∞
‖x‖₂ ≤ ‖x‖₁ ≤ √n · ‖x‖₂
‖x‖_∞ ≤ ‖x‖₁ ≤ n · ‖x‖_∞
```

看 `x = (1,1)`：`L1 = 2`，`L2 = √2 ≈ 1.414`，`L∞ = 1`。维数越高差距越大。

**对偶关系**：`Lp` 的对偶范数是 `Lq`，`1/p + 1/q = 1`。所以 `L1 ↔ L∞`，`L2 ↔ L2`（自对偶）。这解释了为什么 L1 正则化（Lasso）产生稀疏解，而 L2 正则化（Ridge）产生小值解——对偶视角下它们约束的是不同几何。

## 七、图形学里的应用

### 欧氏（L2）

- **默认距离**：光照衰减、SDF、物理碰撞、KD-tree 最近邻
- **Voronoi**：细胞是**凸多边形**，边是中垂线
- **各向同性**：旋转物体时距离场不变，这是它成为默认值的根本原因
- **代价**：`sqrt` 较贵，GPU 上常比较平方值

### 曼哈顿（L1）

- **网格寻路**：四连通网格的 A* 启发函数必须是 L1（用 L2 会高估，破坏可采纳性）
- **L1 Voronoi**：细胞边是**水平、垂直、45° 折线**，看起来像“斜切的城市街区”
- **曼哈顿距离变换**：图像处理里两趟扫描（chamfer）即可，`O(n)`，比精确欧氏距离变换简单得多
- **像素艺术/体素**：栅格化的“距离感”
- **稀疏正则化**：Lasso、TV（全变分）去噪

### 切比雪夫（L∞）

- **八连通网格**：国王移动、Chebyshev 寻路的启发函数
- **L∞ Voronoi**：细胞边全是**轴对齐直线**，形成“方块领地”
- **方形结构元**：形态学膨胀/腐蚀用方核，等价于 L∞ 球
- **盒式 SDF**：`boxSDF` 的近似就是 `max(|x|-hx, |y|-hy)`，本质是 L∞ 的距离
- **棋盘类游戏**：攻击范围、移动步数

### 形态学结构元对照

| 结构元 | 对应度量 |
|---|---|
| 方形核 | L∞ 球 |
| 菱形核 | L1 球 |
| 圆盘核 | L2 球 |

这三者在腐蚀/膨胀里效果不同：方核让角变尖，圆盘核让角变圆，菱形核产生 45° 斜边。

## 八、Voronoi 的形状由度量决定（衔接前文）

这是前面提过但值得展开的一点：

```
L2 Voronoi  → 凸多边形，边为中垂线段
L1 Voronoi  → 边为 0°/45°/90° 线段，可能出现非凸细胞
L∞ Voronoi → 边为 0°/90° 线段，细胞是正交多边形
Lp Voronoi  → 边为超椭圆弧（曲边）
```

Worley 噪声换度量会直接改变视觉：

```glsl
float d = pow(pow(abs(dx), P) + pow(abs(dy), P), 1.0/P);
// P=1 → 菱形细胞（晶体、盐粒）
// P=2 → 圆形细胞（气泡、细胞）
// P=∞ → 方形细胞（马赛克、砖块）
// P=0.5 → 星形/四角形（尖刺、海胆）
```

`P` 就是“细胞形状”的旋钮，比换噪声类型更直接。

## 九、代码

```python
import numpy as np

def lp_dist(a, b, p):
    d = np.abs(np.asarray(a) - np.asarray(b))
    if p == np.inf:
        return d.max()
    return (d ** p).sum() ** (1.0 / p)

# 验证大小关系
x = np.array([3.0, 4.0])
for p in [1, 2, 4, np.inf]:
    print(p, lp_dist(x, np.zeros(2), p))
# 1 → 7.0   2 → 5.0   4 → 4.28   inf → 4.0
```

```glsl
// Worley 噪声里换度量
float worley(vec2 p, float P) {
    vec2 ip = floor(p), fp = fract(p);
    float md = 1e9;
    for (int j = -1; j <= 1; j++)
    for (int i = -1; i <= 1; i++) {
        vec2 g = vec2(i, j);
        vec2 o = hash2(ip + g);
        vec2 r = g + o - fp;
        vec2 a = abs(r);
        float d = (P == 1.0) ? a.x + a.y
                : (P == 2.0) ? length(r)
                : pow(pow(a.x, P) + pow(a.y, P), 1.0 / P);
        md = min(md, d);
    }
    return md;
}
```

## 十、其它常见距离（顺带）

| 距离 | 形式 | 用途 |
|---|---|---|
| 闵可夫斯基 | 即 Lp 通式 | 统一框架 |
| 加权欧氏 | `√(Σ wᵢ(xᵢ-yᵢ)²)` | 各向异性、马氏距离（`w = Σ⁻¹`） |
| 马氏距离 | `√((x-y)ᵀΣ⁻¹(x-y))` | 统计、去相关 |
| 汉明 | 不同位计数 | 编码、哈希 |
| 余弦距离 | `1 - cos θ` | 只关心方向，文本/嵌入 |
| 测地距离 | 网格上最短路 | 曲面上的 Voronoi、纹理展开 |
| 编辑距离 | 插入/删除/替换次数 | 字符串（**不满足三角不等式**的变体存在） |

## 十一、坑

**1. L1/L∞ 的启发函数不能混用**
A* 里启发函数必须 ≤ 真实代价。八连通用 L1 会高估，导致非最优路径；四连通用 L2 也会高估。

**2. 欧氏距离变换不能简单两趟扫描**
L1/L∞ 的 chamfer 两趟扫描是精确的，但 L2 用 chamfer 只是近似。精确欧氏距离变换需要 Felzenszwalb 的抛物线包络算法或 jump flooding。

**3. Lp 的 p 不是随便取**
`p < 1` 破坏三角不等式，Voronoi 会出现“细胞互相侵入”的怪现象。要尖刺效果可以用 `1-|n|` 之类的后处理，而不是直接 `p=0.5`。

**4. 高维下 Lp 区分度下降**
维数升高时，最近邻和最远邻的比值趋近 1（维数灾难），L1/L2/L∞ 的排序差异变小，距离本身失去区分力。

**5. 各向异性**
`L2` 的各向同性只在标准内积下成立。做纹理拉伸、地形坡度时，需要加权度量或直接换成 `p` 调整。

## 一句话总结

三者是同一个 Lp 范数在 `p=1, 2, ∞` 的三个截面，几何上对应菱形、圆、正方形；换度量就等于换“世界观的形状”，Voronoi、Worley 噪声、寻路启发、形态学核都随之改变。**L2 是默认，L1 适合网格与稀疏，L∞ 适合棋盘与方形**。

# 啥是Hermite插值？数学上是指用1阶连续的fade函数及2阶连续的fade函数进行插值的过程吗？
不是。Hermite 插值的定义跟"用几阶连续的 fade"无关，它的定义是：**插值多项式不仅匹配节点上的函数值，还匹配节点上的导数值**。

## 标准定义

最简单的两点三次 Hermite 插值：已知两端点的值 `y0, y1` 和导数 `m0, m1`，构造唯一的三次多项式满足

```
H(0) = y0,  H(1) = y1
H'(0) = m0, H'(1) = m1
```

四个条件定四个系数，解出来是

```
H(t) = h00(t)·y0 + h10(t)·m0 + h01(t)·y1 + h11(t)·m1

h00 = 2t³ - 3t² + 1
h10 = t³ - 2t² + t
h01 = -2t³ + 3t²
h11 = t³ - t²
```

对比 Lagrange 插值：只给 `y0, y1`，两个条件，得到一次多项式 `(1-t)y0 + t·y1`。Hermite 多出来的信息全在导数上。

推广到高阶就是 **quintic Hermite**：再匹配二阶导 `y0'', y1''`，六个条件，五次多项式，六个基函数。

## 你的直觉对了一半

`fade` 曲线确实就是 Hermite 的**值基函数**：

```
1985 版：3t² - 2t³        = h01(t)          三次 Hermite
2002 版：6t⁵ - 15t⁴ + 10t³ = 10t³-15t⁴+6t⁵  五次 Hermite
```

所以"用一阶连续的 fade → C1，用二阶连续的 fade → C2"这个观察是对的，因为这两个 fade 分别来自三次和五次 Hermite 基函数族。但这是**基函数的光滑性**带来的结果属性，不是 Hermite 插值的定义。C1/C2 是"结果的连续性阶数"，Hermite 插值是"构造方法"。

顺带：分段三次 Hermite 样条在节点处 C1（相邻段共享值和一阶导），要到 C2 需要额外条件，比如自然三次样条；Catmull-Rom 是 Hermite 样条的一种，切线用相邻点差分估计。

## 但 Perlin 严格来说不是 Hermite 插值

上一轮我说"Perlin 本质上是 Hermite 插值"，这个说法需要修正。看一维情况：

**真·三次 Hermite**：
```
n(t) = h10(t)·g0 + h11(t)·g1 = t(t-1)²·g0 + t²(t-1)·g1
```
三次多项式。

**Perlin**：
```
n(t) = (1-u(t))·t·g0 + u(t)·(t-1)·g1
```
其中 `1-u = h00`，所以是 `h00(t)·t·g0 + h01(t)·(t-1)·g1`。1985 版是 **4 次**，2002 版是 **6 次**。

它满足同样的四个约束（格点值为 0、格点导数为 g），因为 `u'(0)=u'(1)=0` 让含 `u'` 的项在端点消失。但多项式次数不同，所以**不是唯一的三次 Hermite 多项式**。

差别在于：Perlin 把"导数条件"提前编码进了 `dot(g, d)` 这个线性项里，然后只拿 Hermite 的**值基函数**当混合权重。真正的 Hermite 用的是**导数基函数** `h10, h11`。两者系数不同：

| | 权重 |
|---|---|
| 三次 Hermite | `t(t-1)²` , `t²(t-1)` |
| Perlin | `h00(t)·t` , `h01(t)·(t-1)` |

## 更准确的表述

Perlin 噪声是"**满足 Hermite 型约束（格点值 + 格点梯度）的一类插值**"，但用的是 Hermite 值基函数作为权重、作用在线性场上，不是标准的 Hermite 多项式插值。它的次数比对应的 Hermite 插值高一阶。

这个区别在 2D 张量积下更明显：Perlin 是"四个角点标量贡献的 fade 加权混合"，每个贡献 `dot(g_ij, d_ij)` 本身已经是线性的，混合后是双三次（1985）或双五次（2002）张量积曲面。

```python
def hermite3(t, y0, y1, m0, m1):
    h00 = 2*t**3 - 3*t**2 + 1
    h10 = t**3 - 2*t**2 + t
    h01 = -2*t**3 + 3*t**2
    h11 = t**3 - t**2
    return h00*y0 + h10*m0 + h01*y1 + h11*m1

def perlin1(t, g0, g1):
    u = 3*t*t - 2*t*t*t          # h01
    return (1-u)*t*g0 + u*(t-1)*g1
```

两者在 `t=0, 1` 处值和导数都一致，中间不同。

## 一句话总结

Hermite 插值 = 匹配值和导数的插值方法；fade 曲线是 Hermite 的**值基函数**，选三次还是五次决定了结果是 C1 还是 C2，这是结果的连续性，不是定义；Perlin 借用了这套基函数，但因为把梯度编码进了 `dot(g,d)`，它本身不是严格意义的三次/五次 Hermite 插值。

# 啥是插值？英文是啥？数学定义是怎么样的？线性插值 双线性插值 三线性插值 多项式插值 Hermite插值 b样条插值 贝塞尔曲线 贝塞尔插值 nurbs等解释。另外内插 外插 内推 外推又是啥
## 一、插值的定义

英文 **interpolation**。

数学定义：给定节点 `x_0 < x_1 < ... < x_n` 和对应的值 `y_0, ..., y_n`，在一个函数空间 `Φ` 中找一个函数 `f`，使得

```
f(x_i) = y_i,   i = 0, 1, ..., n
```

然后在任意 `x` 处用 `f(x)` 近似真实函数值。

四个要素：

1. **节点**（nodes / knots）：已知数据点的位置
2. **函数空间** `Φ`：多项式、分段多项式、有理函数……
3. **插值条件**：必须严格过点
4. **唯一性**：`Φ` 的维数等于条件数，且相应矩阵非奇异时唯一

## 二、先分清三件事

这是最容易混的地方：

| 概念 | 英文 | 是否过点 |
|---|---|---|
| 插值 | interpolation | **必须**过所有点 |
| 逼近/拟合 | approximation / fitting | 不必过点，最小化误差 |
| 平滑 | smoothing | 允许偏差换光滑 |

**贝塞尔曲线和 B 样条默认属于"逼近"**——它们不穿过控制点（端点除外）。这点后面会反复用到。

## 三、线性插值

**Linear interpolation**，俗称 lerp。`Φ = P_1`（一次多项式），两个节点：

```
f(x) = y_0 + (y_1 - y_0) · (x - x_0) / (x_1 - x_0)
```

分段线性就是每个区间独立做一次。误差 `O(h²)`：

```
|f - L| ≤ (h²/8) · max|f''|
```

## 四、双线性 / 三线性

**Bilinear / Trilinear interpolation**。它们不是"线性的"，而是**张量积**。

双线性：四个角点 `(x0,y0), (x1,y0), (x0,y1), (x1,y1)`，空间是

```
Φ = span{1, x, y, xy}
```

四维，正好四个条件。做法是先沿 x 做两次 lerp，再沿 y 做一次：

```
f(x,y) = (1-u)(1-v)·y00 + u(1-v)·y10 + (1-u)v·y01 + uv·y11
u = (x-x0)/(x1-x0),  v = (y-y0)/(y1-y0)
```

**关键限制：双线性插值要求四个点是矩形（张量积网格）排列**。任意四个散点没有唯一的双线性插值。

三线性：八个角点，`span{1,x,y,z,xy,yz,zx,xyz}`，八维。GPU 纹理采样的硬件电路做的就是这件事，mipmap 层间混合也是。

## 五、多项式插值

**Polynomial interpolation**。`Φ = P_n`（次数 ≤ n），`n+1` 个点定 `n+1` 个系数，唯一。

**Lagrange 形式**：

```
f(x) = Σ y_i · L_i(x),   L_i(x) = Π_{j≠i} (x - x_j)/(x_i - x_j)
```

**Newton 形式**（差商，增量计算更方便）：

```
f(x) = y_0 + fx-x_0 + fx-x_0(x-x_1) + ...
```

**致命缺陷：Runge 现象**。等距节点、高次时端点剧烈振荡。经典反例 `f(x) = 1/(1+25x²)` 在 `[-1,1]` 上，`n` 越大端点误差越大。所以实践中**几乎不用高次全局多项式**，改用分段或样条。Chebyshev 节点可以缓解（使 Lebesgue 常数最优），但工程上还是分段更省事。

## 六、Hermite 插值

**Hermite interpolation**：不仅匹配值，还匹配导数。三次 Hermite 用两个节点的值和一阶导，共四个条件：

```
H(t) = h00·y0 + h10·m0 + h01·y1 + h11·m1
h00 = 2t³-3t²+1,  h10 = t³-2t²+t
h01 = -2t³+3t²,   h11 = t³-t²
```

误差 `O(h⁴)`，比线性好得多。五次 Hermite 再匹配二阶导，`O(h⁶)`。

**Catmull-Rom 样条**是分段三次 Hermite 的特例：节点导数用相邻点差分估计 `m_i = (y_{i+1} - y_{i-1})/2`，不需要额外提供导数数据，且能插值所有点。

## 七、样条插值

**Spline interpolation**：分段低次多项式 + 节点处连续性约束。

**三次样条**（cubic spline）：分段三次，要求 `C²` 连续。`n+1` 个点有 `n` 段 × 4 系数 = `4n` 未知，插值条件 `n+1`，内部节点 `C⁰/C¹/C²` 各 `3(n-1)`，合计 `4n - 2`，差 2 个自由度 → 需要两个边界条件：

- **自然样条**：两端二阶导为 0
- **钳制样条**：给定两端一阶导
- **周期样条**：首尾值、一阶导、二阶导相等

误差 `O(h⁴)`，全局光滑，是"既光滑又不过冲"的实用首选。代价是**全局耦合**——解一个三对角线性系统，改一个点全曲线变。

## 八、B 样条

**B-spline**。先分清两个东西：

**1. 基函数** `N_{i,p}(t)`，由节点向量 `t_0 ≤ t_1 ≤ ...` 定义，Cox-de Boor 递推：

```
N_{i,0}(t) = 1  若 t_i ≤ t < t_{i+1}，否则 0
N_{i,p}(t) = (t - t_i)/(t_{i+p} - t_i) · N_{i,p-1}(t)
           + (t_{i+p+1} - t)/(t_{i+p+1} - t_{i+1}) · N_{i+1,p-1}(t)
```

**2. 曲线**：

```
C(t) = Σ N_{i,p}(t) · P_i
```

性质：

- **局部支撑**：`N_{i,p}` 只在 `[t_i, t_{i+p+1})` 非零，改一个 `P_i` 只影响局部 `p+1` 段
- **凸包性**：曲线在控制点凸包内
- **连续性** `C^{p-k}`，`k` 是节点重数
- **次数与控制点数解耦**：`p` 固定，控制点数任意，这是它相对贝塞尔的根本优势
- **一般不插值控制点**。节点重数 `= p+1`（clamped）时端点插值

**"B 样条插值"**是另一个问题：给定要穿过的点 `Q_j`，反解控制点

```
N · P = Q
```

因为局部支撑，`N` 是带状矩阵，求解很便宜。这是 CAD 里常用的曲线重建方式。

## 九、贝塞尔曲线

**Bézier curve**，Bernstein 基：

```
B_{i,n}(t) = C(n,i) · t^i · (1-t)^{n-i}
C(t) = Σ_{i=0}^{n} B_{i,n}(t) · P_i
```

性质：

- **端点插值**：`C(0)=P_0`，`C(1)=P_n`，端点切线沿 `P_0P_1` 和 `P_{n-1}P_n`
- **凸包性、变差缩减**
- **全局影响**：改一个控制点整条曲线都变（Bernstein 基全局非零）
- **次数随控制点数增长**：`n+1` 个控制点就是 `n` 次

前两条让它交互设计很直观，后两条是它的死穴，所以实际系统都用**分段贝塞尔**（每段固定低次），而分段贝塞尔在数学上正好是 B 样条的一个特例。

**关于"贝塞尔插值"**：这不是标准术语。贝塞尔曲线是**逼近**控制点的，中间控制点不在曲线上。如果你想让曲线穿过给定点，那叫**贝塞尔曲线拟合/插值**，做法是解线性系统 `B · P = Q` 反求控制点。因为 Bernstein 基全局支撑，这个矩阵稠密，`n` 大时病态，所以实践中更常用 B 样条做插值。

## 十、NURBS

**Non-Uniform Rational B-Spline**。在 B 样条上加权：

```
C(t) = Σ N_{i,p}(t) · w_i · P_i  /  Σ N_{i,p}(t) · w_i
```

三个词拆开：

- **Non-Uniform**：节点向量非均匀分布（均匀 B 样条是特例）
- **Rational**：有理形式，多了权重 `w_i` 和分母归一化
- **B-Spline**：基函数还是 B 样条

**为什么要有理**：多项式**无法精确表示圆**（圆弧的参数方程含根号），但有理性可以。所以 CAD 标准（IGES、STEP）用 NURBS，因为要精确存圆锥曲线。`w_i` 还提供额外的形状控制（投影几何解释：NURBS 是四维 B 样条在 `w=1` 超平面上的投影）。

代价：分母让求导、求交、积分都变复杂，且有理形式下凸包性、变差缩减只部分保留。

## 十一、内插 / 外插 / 内推 / 外推

**这四组词基本是译名问题，不是数学区分**：

| 中文 | 英文 | 含义 |
|---|---|---|
| 插值 / 内插 | interpolation | 在节点范围**内**求值 |
| 外插 / 外推 | extrapolation | 在节点范围**外**求值 |

- **"内插"**是 interpolation 的早期译法，中文数学教材里"线性内插法"很常见，和"插值"完全同义。工程上有时特指"在已有采样之间插入新采样"（重采样/上采样），但数学定义一致。
- **"外推"**就是 extrapolation，"外插"是同义旧译。
- **"内推"**不是标准数学术语，口语里多指插值，也可能是"推断（inference）"的误用——统计学的推断是另一回事。

**外推的风险**：插值误差界依赖节点区间内的导数界，外推时这个界失效。线性外推（沿端点切线延伸）还算可控，**多项式外推是灾难**（Runge 现象在外推区更猛）。工程上的稳妥做法：

- 常数外推（clamp，纹理采样 `CLAMP_TO_EDGE` 就是这个）
- 周期外推（wrap）
- 镜像外推（mirror）
- 用端点切线做线性外推

## 十二、对比与选型

| 方法 | 是否过点 | 光滑性 | 局部性 | 典型用途 |
|---|---|---|---|---|
| 线性 | 是 | C⁰ | 局部 | 查表、lerp |
| 双/三线性 | 是（网格点） | C⁰ | 局部 | 纹理采样、体数据 |
| 全局多项式 | 是 | C^∞ | **全局** | 理论分析，实践少 |
| Hermite | 是（含导数） | C¹ | 局部 | 动画曲线、Catmull-Rom |
| 三次样条 | 是 | C² | **全局** | 数据平滑、轨迹 |
| B 样条 | 否（可反解） | C^{p-k} | **局部** | CAD、字体、曲线设计 |
| 贝塞尔 | 仅端点 | C^∞（单段） | **全局** | 交互设计、字体 |
| NURBS | 否 | C^{p-k} | 局部 | 工业 CAD、精确圆锥曲线 |

选型逻辑：

- 只要连续、便宜 → 线性/双线性
- 要光滑且过点 → 三次样条或 Catmull-Rom
- 要局部可编辑 → B 样条 / NURBS
- 要精确表示圆和圆锥 → NURBS
- 交互拖控制点 → 贝塞尔（单段低次）

回到你前几轮的 Perlin 问题：Perlin 用的是 Hermite 的**值基函数**（fade 曲线）作为混合权重，作用在 `dot(g,d)` 线性场上，所以它是"满足 Hermite 型约束的张量积混合"，既不是标准 Hermite 插值，也不是双线性插值——双线性用的是 `u, v` 而不是 `fade(u), fade(v)`，这也正是 Perlin 没有网格折痕的原因。

# 啥是spline，有哪些样条？数学定义及特性有啥？
## 一、词源与核心思想

英文 **spline**。原指造船用的弹性细木条：两端压铁固定，木条自然弯曲成一条光滑曲线。物理上它自动取**最小弯曲能量**的形状。

这个物理直觉直接对应数学性质：自然三次样条在所有满足插值条件的 C² 函数中，最小化

```
∫ (f''(x))² dx
```

所以"样条"的核心不是"某个多项式"，而是：**分段低次多项式 + 节点处强制光滑 + 由能量/约束定形**。

## 二、数学定义

给定节点（knots）`a = x_0 < x_1 < ... < x_n = b`。

**定义**：函数 `S: [a,b] → ℝ` 称为 `p` 次样条，若

1. 在每个子区间 `[x_{i-1}, x_i]` 上，`S` 是次数 `≤ p` 的多项式；
2. `S ∈ C^{p-1}([a,b])`，即在内部节点处直到 `p-1` 阶导数连续。

样条空间记作 `S_p(Δ)`。允许节点重数 `k_i` 时，该点光滑度降为 `C^{p-k_i}`。

## 三、自由度计数（理解一切的关键）

`n` 段、每段 `p+1` 个系数：

```
未知数        n(p+1)
内部节点约束   (n-1)·p       每个节点 p 个连续性条件（值 + 1..p-1 阶导）
```

剩余自由度：

```
dim S_p = n(p+1) - (n-1)p = n + p
```

若节点数为 `N = n+1`，则 `dim = N + p - 1`。

**这直接解释了为什么需要边界条件**：三次样条（`p=3`）插值 `N` 个点，空间维数 `N+2`，插值条件只占 `N` 个，**差 2 个自由度**。

## 四、分类

```
样条
├─ 按次数
│   ├─ 一次（分段线性，C⁰）
│   ├─ 二次（C¹）
│   ├─ 三次（C²）← 最常用
│   └─ 高次（五次、七次，C⁴/C⁶）
├─ 按边界/约束
│   ├─ 自然样条       S''(a)=S''(b)=0
│   ├─ 钳制样条       S'(a), S'(b) 给定
│   ├─ 周期样条       首尾值/一/二阶导相等
│   └─ not-a-knot     第三个节点处三阶导连续
├─ 按构造方式
│   ├─ 插值样条（过所有点）
│   │   ├─ 三次样条插值
│   │   ├─ Hermite 样条 / Catmull-Rom
│   │   ├─ PCHIP（保单调）
│   │   ├─ Akima
│   │   └─ 张力样条
│   └─ 逼近样条（不过控制点）
│       ├─ B 样条（均匀/非均匀/周期/clamped）
│       ├─ NURBS
│       ├─ T 样条
│       └─ M 样条
└─ 按维度
    ├─ 张量积样条（网格）
    └─ 散点样条：薄板样条 TPS、径向基
```

## 五、关键类型逐个说

### 1. 三次样条插值

最经典。`S''(x_i) = M_i` 为未知量，得到三对角系统：

```
μ_i M_{i-1} + 2M_i + λ_i M_{i+1} = d_i

μ_i = h_{i-1}/(h_{i-1}+h_i),   λ_i = 1 - μ_i
d_i = 6/(h_{i-1}+h_i) · [ (y_{i+1}-y_i)/h_i - (y_i-y_{i-1})/h_{i-1} ]
```

自然边界 `M_0 = M_n = 0`。每段用：

```
S(x) = M_i (x_{i+1}-x)³/(6h_i) + M_{i+1}(x-x_i)³/(6h_i)
     + (y_i - M_i h_i²/6)(x_{i+1}-x)/h_i
     + (y_{i+1} - M_{i+1}h_i²/6)(x-x_i)/h_i
```

特性：`C²`、误差 `O(h⁴)`、**全局耦合**（改一个点整条变）、**会过冲**。

### 2. Hermite 样条 / Catmull-Rom

分段三次 Hermite，`C¹`。Catmull-Rom 用相邻差分估切线：

```
m_i = (y_{i+1} - y_{i-1})/2
```

`P(t) = 0.5·[2P_1 + (-P_0+P_2)t + (2P_0-5P_1+4P_2-P_3)t² + (-P_0+3P_1-3P_2+P_3)t³]`

特性：**局部**（改一点影响 4 段）、过点、`C¹`、不过冲程度比三次样条温和。动画/相机路径的事实标准。缺点：均匀参数化在点距悬殊时会出现尖点或自交，要用**向心参数化**（centripetal，`α=0.5`）。

### 3. PCHIP（保单调）

Fritsch–Carlson 条件：限制切线 `m_i` 的符号和大小，使得每段单调性与数据一致。特性：**不过冲**、保单调、`C¹`、局部。缺点是光滑度不如 `C²`，且曲线"偏硬"。数据有物理约束（浓度、概率、不能为负的量）时首选。

### 4. Akima

用相邻五点差分估斜率，局部、`C¹`、抗局部突变。比 Catmull-Rom 更"贴身"，比 PCHIP 更自然。

### 5. 张力样条（tension spline）

在三次样条里引入张力参数 `σ`：

- `σ → 0`：退化为三次样条
- `σ → ∞`：趋近分段线性

中间值可调，是**抑制过冲的连续旋钮**。地质、测绘里常用。

### 6. B 样条

**这是最容易误解的一点：B 样条不是"另一类曲线"，它是样条空间的一组基**（B = basis）。任何 `p` 次样条都能唯一写成

```
S(t) = Σ N_{i,p}(t) · c_i
```

`c_i` 是 B 样条系数。Cox–de Boor 递推定义基函数，性质：

- 非负、**单位分解** `Σ N_{i,p} ≡ 1`
- **局部支撑** `[t_i, t_{i+p+1})`
- 连续性 `C^{p-k}`（`k` 为节点重数）
- **凸包性**、**变差缩减**（TVD）

节点向量分类：

| 类型 | 节点 | 端点行为 |
|---|---|---|
| 均匀 | 等距 | 不插值端点 |
| 非均匀 | 任意 | 不插值端点 |
| clamped（开） | 首尾重数 `p+1` | 插值端点 |
| 周期 | 循环 | 首尾 `C^{p-1}` 闭合 |

**B 样条插值**是反问题：给定 `Q_j`，解 `N·c = Q`。因局部支撑，`N` 是带状矩阵，`O(n)` 可解。

### 7. NURBS

有理形式，多一组权重：

```
C(t) = Σ N_{i,p} w_i P_i / Σ N_{i,p} w_i
```

存在理由是**多项式无法精确表示圆**（圆弧参数方程含根号），有理性可以。所以 CAD 标准（IGES/STEP）用它。几何解释：四维 B 样条在 `w=1` 超平面上的中心投影。

### 8. T 样条

允许 T 形节点（一条边的端点落在另一条边中间），解决 NURBS 拼接时产生冗余控制行的问题。等几何分析（IGA）里重要。

### 9. 薄板样条（TPS）

二维散点插值。最小化弯曲能量

```
∫∫ (f_xx² + 2f_xy² + f_yy²) dxdy
```

解的形式：

```
f(x) = Σ w_i · φ(|x - x_i|) + a_0 + a_1 x + a_2 y,   φ(r) = r² log r
```

是径向基函数插值的原型，图像变形、配准、散点拟合常用。注意 `N` 大时是**稠密**系统，`O(N³)`，需要近似方法（快速多极、landmark 子集）。

## 六、特性对比

| 类型 | 过点 | 光滑性 | 局部性 | 过冲 | 收敛阶 |
|---|---|---|---|---|---|
| 分段线性 | 是 | C⁰ | 局部 | 无 | O(h²) |
| 三次样条 | 是 | C² | **全局** | **有** | O(h⁴) |
| Catmull-Rom | 是 | C¹ | 局部 | 轻 | O(h⁴) |
| PCHIP | 是 | C¹ | 局部 | **无** | O(h³) |
| Akima | 是 | C¹ | 局部 | 轻 | O(h³) |
| 张力样条 | 是 | C² | 全局 | 可调 | O(h⁴) |
| B 样条曲线 | 否（可反解） | C^{p-k} | **局部** | 无（凸包） | — |
| NURBS | 否 | C^{p-k} | 局部 | 无 | — |
| TPS | 是（散点） | 全局光滑 | **全局** | 有 | — |

一般 `p` 次样条插值误差 `O(h^{p+1})`（需 `f ∈ C^{p+1}`）。

## 七、常见坑

**1. 过冲 ≠ Runge 现象**
Runge 是**高次全局多项式**在等距节点端点的振荡。三次样条的过冲是另一回事：数据有阶跃或陡变时，`C²` 约束强迫曲线"提前转弯"，产生局部超调。解决办法是 PCHIP、张力样条、或单调性限制。

**2. 参数化方式决定成败**
点列插值时，`t_i` 怎么取很关键：

- 均匀：`t_i = i`，点距悬殊时尖点、自交
- 弦长：`t_i - t_{i-1} = |P_i - P_{i-1}|`，改善但仍有尖点
- **向心**：`|P_i - P_{i-1}|^{0.5`}，理论保证无尖点无自交，推荐默认

**3. 边界条件的影响是全局的**
自然 vs 钳制 vs not-a-knot，差异从端点向内部衰减但不会消失。数据端点有物理意义（速度、斜率）时用钳制。

**4. "B 样条曲线"和"B 样条插值"是两件事**
前者是 `Σ N_i c_i`（系数即控制点，曲线不过 `c_i`）；后者是解 `N c = Q` 让曲线过 `Q`。

**5. 高次样条不总更好**
`p ≥ 5` 时振荡加剧、计算量上升，除非需要 `C⁴` 以上光滑（如高阶 PDE 的等几何分析），否则三次足够。

## 八、代码

```python
import numpy as np

def cubic_spline_natural(x, y):
    """自然三次样条，返回分段系数 (a,b,c,d)，S_i = a + b*dx + c*dx^2 + d*dx^3"""
    n = len(x) - 1
    h = np.diff(x)
    # 三对角系统求 M_i = S''(x_i)
    A = np.zeros((n+1, n+1)); r = np.zeros(n+1)
    A[0,0] = 1.0; A[n,n] = 1.0
    for i in range(1, n):
        A[i, i-1] = h[i-1]
        A[i, i]   = 2*(h[i-1] + h[i])
        A[i, i+1] = h[i]
        r[i] = 6*((y[i+1]-y[i])/h[i] - (y[i]-y[i-1])/h[i-1])
    M = np.linalg.solve(A, r)
    a, b, c, d = y[:-1].copy(), np.zeros(n), M[:-1]/2, np.zeros(n)
    for i in range(n):
        b[i] = (y[i+1]-y[i])/h[i] - h[i]*(2*M[i] + M[i+1])/6
        d[i] = (M[i+1] - M[i])/(6*h[i])
    return a, b, c, d

def catmull_rom(p0, p1, p2, p3, t):
    t2, t3 = t*t, t*t*t
    return 0.5*((2*p1) + (-p0+p2)*t
                + (2*p0-5*p1+4*p2-p3)*t2
                + (-p0+3*p1-3*p2+p3)*t3)
```

实际工程里 `scipy.interpolate` 的 `CubicSpline`（可选 `bc_type='natural'/'clamped'/'periodic'/'not-a-knot'`）、`PchipInterpolator`、`Akima1DInterpolator`、`make_interp_spline`（B 样条）、`RBFInterpolator`（含 TPS）已覆盖绝大多数场景。

## 九、和前面讨论的衔接

- **Perlin 噪声**用的 fade 曲线就是 Hermite 值基函数，但作用在 `dot(g,d)` 上，不是标准样条插值；fBm 多倍频叠加本质是"不同尺度的样条场求和"。
- **地形高度曲线、颜色 LUT、动画关键帧**基本都用 Catmull-Rom 或 PCHIP——要局部可编辑、不过冲。
- **GPU 纹理采样**的硬件三线性插值是分段线性的张量积，`C⁰`，靠 mipmap 掩盖折痕。
- **CAD/字体**用 B 样条/NURBS，因为要局部编辑 + 精确圆锥曲线；**贝塞尔**是 B 样条的 clamped 特例（`p+1` 个控制点、单段）。
