# 海洋渲染中octave 波浪是啥
**结论先行**：海洋渲染里的 "octave 波浪"不是某一种特定波形，而是**把海面按空间尺度分层叠加**的思路——每个 octave 代表一个频率层级（大涌浪 → 中波 → 碎波 → 毛细涟漪），频率逐级翻倍、振幅逐级衰减，合起来就是"大浪套小浪"的真实海面。

---

## 一、为什么需要 octave

单一正弦波 / 单个 Gerstner 波太"干净"，看起来像蓝色果冻。真实海洋的能量分布在**所有尺度**上同时存在：

- 几百米的长涌浪（定基调）
- 几十米的中波（结构感）
- 几米的碎波（锯齿感）
- 厘米级的毛细波（高光细节）

所以做法是：把不同尺度的波**分层叠加**，每一层就叫一个 **octave**（借用音乐里"八度"的概念——频率翻倍）。

---

## 二、数学本质

### 1. Gerstner / 正弦波叠加语境

```glsl
// 伪代码：多 octave Gerstner 叠加
vec3 pos = basePos;
float freq = 1.0;
float amp  = baseAmp;
float steepness = baseSteep;

for (int i = 0; i < numOctaves; i++) {
    pos += gerstnerWave(dir[i], wavelength * freq, amp, steepness, time);
    freq *= 2.0;          // 波长减半，频率翻倍
    amp  *= 0.5;          // 振幅衰减（gain）
    steepness *= steepnessDecay;
}
```

三个核心参数（和 FBM 完全一致）：

| 参数 | 含义 | 典型值 |
|---|---|---|
| `lacunarity` | 每层频率倍增系数 | 1.8 ~ 2.0 |
| `gain` | 每层振幅衰减比例 | 0.4 ~ 0.5 |
| `numOctaves` | 叠加层数 | 4 ~ 8（再高收益递减）|

Crest、SimpleOcean 这类成熟海洋系统就是这样组织的：每个 octave 里再塞多条不同方向的子波，避免规则感 。

### 2. FBM 噪声语境（法线 / 细节层）

几何位移管大波，碎波细节常用 FBM 噪声补：

$$h(x) = \sum_{i=0}^{n} a^i \cdot \text{noise}(b^i \cdot x)$$

- `b ≈ 2`（频率翻倍）
- `a ≈ 0.5`（振幅减半）

这一步通常作用在**法线贴图或位移细节**上，而不是宏观几何 。

### 3. FFT 频谱语境

FFT 海洋（Tessendorf）本质也是在解"所有波数分量之和"，只是分量不是手动分层，而是由 Phillips / JONSWAP 频谱决定能量分布。工程上仍会把频谱按波长区间划分成 octave 来调参——比如"Crest 的 OceanWaveSpectrum 按 octave 组织，每个 octave 是波长翻倍的一档" 。

---

## 三、每个 octave 在视觉上负责什么

| Octave | 波长量级 | 作用 |
|---|---|---|
| 第 1 层 | 千米级 | 整体海面起伏、远景轮廓 |
| 第 2~3 层 | 百米~十米 | 主浪形、波峰走向 |
| 第 4~5 层 | 米级 | 波峰破碎感、锯齿 |
| 第 6+ 层 | 亚米级 | 毛细波、法线高频细节 |

> 💡 经验值：几何位移 4~5 个 octave 足够；法线细节可以再叠 2~3 个。超过 6~8 个 octave 肉眼基本看不出区别，但算力白白翻倍 。

---

## 四、工程实现里的关键细节

**1. 方向要打散**
每个 octave 别用同一方向，否则像"阅兵方阵"。通常给每层一个方向偏移，或用旋转矩阵把采样坐标转一点角度 。

**2. 振幅衰减不是必须严格 0.5**
`gain` 调大（如 0.7）→ 高频更强势，海面更"暴躁"；调小 → 更平静柔和。

**3. Steepness 也要随 octave 衰减**
高频波如果陡度不降，波峰会自交、穿模。Gerstner 波的 Jacobian 行列式变负就是"折叠"，也是白沫产生的位置 。

**4. LOD 联动**
远处像素采样降 octave 数：近景 4~5 octave，中景 2~3，远景 1。这是实时海洋渲染的标准优化 。

## 五、常见误区

> ⚠️ **误区 1**：octave 越多海面越真实  
> 错。过多 octave 会带来：算力爆炸、高频噪点、tiling 感增强。真实感来自"频谱能量分布合理"，不是层数堆叠。

> ⚠️ **误区 2**：octave 是物理上独立的"一波"  
> 不是。它只是**尺度分解**的抽象——真实海洋没有"第 3 octave 波"，只有连续谱。octave 是我们为了方便控制而做的离散化。

> ⚠️ **误区 3**：Gerstner octave 和 FBM octave 是一回事  
> 思路同源（倍频+衰减），但前者是**有向周期波位移**，后者是**无向噪声细节**。通常两者配合使用：Gerstner 管几何，FBM 管法线。

---

## 六、一句话建立直觉

把海面想象一幅画：
- **低频 octave** = 大排刷铺的底色（远看的形状）
- **中频 octave** = 中号笔扫的结构（浪的走向）
- **高频 octave** = 细毛笔点的最终纹理（波尖的毛糙感）

三者缺一，海面就会"假"——要么像塑料，要么像果冻，要么像噪点图。
