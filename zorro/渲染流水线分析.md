# 引擎渲染流水线分析（基于 `sdk/include/ig/render`）

本文档基于 `sdk/include/ig/render` 子目录下的关键头文件，分析引擎渲染系统的核心类、职责划分与渲染流水线的实现方式。

## 1. 关键类总览

| 类 | 头文件 | 职责 |
|----|--------|------|
| `Render` | `Render.h` | 渲染器主控类，持有所有渲染子系统，管理全局渲染开关与参数（散射、HDR、雾、SSAO、SSR、DOF、TAA 等），暴露给应用层 |
| `RState` | `RState.h` | 渲染状态抽象层，封装底层图形 API（D3D11/OpenGL/Vulkan）的状态设置（depth/blend/cull/viewport/纹理/采样器/Shader 参数），由各 API 后端实现 |
| `RExec` | `RExec.h` | 渲染执行器，组织一帧的渲染流程，管理相机/投影/视锥栈，调度阴影、反射、G-Buffer、前向/延迟、散射、雾、后处理等 pass |
| `RScene` | `RScene.h` | 场景可见性收集器，对 `World` 做视锥剔除，收集可见 Object、Light、Decal、UI、Cloud、Radar，分类为不透明/透明 surface 列表 |
| `RLights` | `RLights.h` | 光照展开器，针对每个光源计算影响范围、收集受光 surface、渲染阴影贴图、提交延迟光照 quad |
| `RPost` | `RPost.h` | 后处理模块，执行 SSAO、散射、体积光、雾、Glow、HDR、TAA、DOF、LLNV、Radar、合成等屏幕空间 pass |
| `RClouds` | `RClouds.h` | 体积云渲染器 |
| `AtmosphereModel` | `AtmosphereModel.h` | 大气散射模型，预计算透射率/散射/辐照度 LUT 并绑定到材质 |
| `RenderSurface` | `RenderSurface.h` | 渲染表面，表示一个可绘制 surface（Object + surface id + 材质 + 变换），是流水线中的最小绘制单元 |

### 1.1 拥有与依赖关系

```
Render (拥有)
  ├─ RState*   m_state      （底层状态，由 API 后端实现）
  ├─ RExec*    m_renderer   （执行器，组织帧流程）
  ├─ RPost*    m_post       （后处理）
  └─ RClouds*  m_clouds     （体积云）

RExec (拥有引用)
  ├─ Render*  m_render
  ├─ RState*  m_state
  └─ 调度 RScene / RLights / RPost 完成一帧

RScene (引用)
  ├─ RExec*   m_renderer
  └─ World*   m_world

RLights (引用)
  └─ World*   m_world

RPost (引用)
  ├─ Render*  m_render
  ├─ RState*  m_state
  ├─ RExec*   m_renderer
  └─ AtmosphereModel* m_atmosphere_model
```

## 2. 渲染流水线

### 2.1 帧级生命周期

```
Render::update(dt)         // 每帧入口
  └─ RExec::beginFrame()   // 帧开始，初始化状态
       └─ RPost::beginFrame()
       └─ RState::beginFrame()
  └─ Render::renderViewport(world, proj, mv, caller)
       └─ RExec::renderViewport(world, caller)
            └─ RExec::render_world(world, caller)   // 见 2.2
  └─ RExec::endFrame()     // 帧结束，提交
       └─ RPost::endFrame()
       └─ RState::endFrame()
       └─ RState::flushRender() / flushGPU()
```

### 2.2 主渲染流程 `RExec::render_world`

`RExec::render_world` 是核心调度入口，按顺序执行：

```
render_world(world, caller)
  ├─ render_prepare(world, caller)         // 准备：更新相机、视锥、WGS 局部变换、cbuffer
  ├─ render_environment(world)             // 环境贴图/IBL 更新（environment_texture、球谐系数）
  ├─ RScene::getIntersection(bf)           // 视锥剔除，收集可见 surface/light/decal/cloud
  ├─ render_shadows(scene, lights)         // 阴影 pass（见 2.3）
  ├─ render_reflections(scene)             // 反射 pass（2D / Cube，见 2.4）
  ├─ render_scene(scene, lights, screen, caller, proj_normal)  // 主场景（见 2.5）
  │     ├─ render_scene_forward / 延迟路径
  │     ├─ post_ssao / post_ssr
  │     ├─ post_composite_deferred
  │     ├─ post_scattering                  // 天空背景与大气散射
  │     ├─ post_volumetric
  │     ├─ post_fog
  │     └─ render_transparent               // 透明物体（含散射/雾/TAA 后处理）
  ├─ render_clouds(scene, screen)           // 体积云
  ├─ post_sharpen(screen)                   // 锐化
  ├─ post_render(screen)                    // 最终合成与输出
  └─ render_ui(scene, mode, post_taa)       // UI
```

### 2.3 阴影 pass `RExec::render_shadows` → `RLights::renderShadows`

```
RLights::renderShadows(scene, exclude)
  ├─ 遍历场景光源
  ├─ 对 LightWorld：
  │    ├─ updateLightWorldParameters(light)   // 计算级联视锥、投影矩阵
  │    ├─ get_light_world_shadow_surfaces(light, exclude, scene)  // 收集阴影投射 surface
  │    └─ render_shadow_world(light, surfs)   // 渲染 4 级 CSM 阴影贴图
  ├─ 对 LightOmni：render_light_omni_shadow   // 立方体阴影
  ├─ 对 LightProj：render_light_proj_shadow   // 透视阴影
  └─ 提交阴影参数到 shader（setShaderCSMParameters）
```

`RLights` 内部维护 `m_light_shadow_projections[4]`、`m_light_shadow_projection_z`、`m_light_shadow_projections_xy[4]` 等级联阴影数据，通过 `setShaderCSMParameters()` 上传到 shader。

### 2.4 反射 pass `RExec::render_reflections`

```
render_reflections(scene)
  ├─ get_reflection_surfaces(surfaces)       // 收集需要反射的 surface
  ├─ render_reflections_2d(world, surfs)     // 2D 平面反射
  └─ render_reflections_cube(world, surfs)   // 立方体反射
       └─ render_reflect_scene(scene, shadows)  // 递归渲染场景到反射 RT
```

### 2.5 主场景渲染 `RExec::render_scene`

引擎支持 **前向渲染** 与 **延迟渲染** 两条路径，由 `render_scene_forward` 与延迟分支切换。

#### 2.5.1 延迟渲染路径（默认）

```
render_scene(scene, lights, screen, caller, proj_normal)
  ├─ render_opacity_gbuffer(scene, screen)   // 几何 pass：填充 G-Buffer
  │     ├─ render_pre_depth_surfaces         // Pre-Depth（可选）
  │     ├─ render_deferred_opacity_surfaces  // 写 G-Buffer
  │     └─ render_deferred_decals            // Decal 写 G-Buffer
  ├─ RLights::renderDeferredLights(scene, is_water)  // 光照 pass
  │     ├─ render_deferred_light_world       // 全局光/太阳光
  │     ├─ render_deferred_light_proj        // 投影光
  │     ├─ render_deferred_light_omni        // 全向光
  │     └─ render_deferred_light_point       // 点光（最多 MAX_LIGHT_POINT_PER_RENDER=4）
  ├─ post_ssao(screen)                       // SSAO
  ├─ post_ssr(screen)                        // SSR
  └─ post_composite_deferred(scene, screen)  // 合成延迟结果
```

**G-Buffer 结构**（`RState.h` 中 `GBuffer`）：

| 纹理 | 格式 | 内容 |
|------|------|------|
| `albedo` | RGBA8 | rgb: 漫反射颜色, a: occlusion |
| `shading` | RGBA8 | r: metalness, g: f0, b: translucent, a: microfiber |
| `normal` | RGBA8 | rgb: 法线, a: roughness |
| `depth` | RGBA32F | 深度 |
| `material_mask` | R32U | 材质掩码 |
| `glow` | R16F | 辉光强度 |
| `delta_position` | — | 位置增量（用于 TAA） |

**延迟光照缓冲**（`RenderBuffers`）：

| 纹理 | 格式 | 内容 |
|------|------|------|
| `lights_color` | RG11B10F | 漫反射光照 |
| `lights_specular` | RG11B10F | 镜面光照 |
| `ssao` | R8 | SSAO |
| `ssgi` | RG11B10F | SSGI |
| `ssr` | RGBA16F | rgb: 反射颜色, a: alpha |
| `ssr_depth` | R8 | 反射深度 |

#### 2.5.2 前向渲染路径 `render_scene_forward`

```
render_scene_forward(scene, lights, screen)
  ├─ render_opacity(scene, screen, lights)   // 不透明物体，逐光源计算光照
  └─ （透明物体在 render_transparent 中处理）
```

### 2.6 透明物体 pass `RExec::render_transparent`

```
render_transparent(scene, screen, lights, post_scattering, post_fog, post_taa)
  ├─ render_transparent_decals                // 透明 Decal
  └─ 逐透明 surface：
       ├─ RLights::renderTransparentSurfaces  // 逐光源光照
       ├─ 若 post_scattering：post_scattering  // 散射（天空背景）
       ├─ 若 post_fog：post_fog                // 雾
       └─ 若 post_taa：TAA 处理
```

### 2.7 后处理流水线 `RPost`

`RPost` 是后处理总管，由 `RExec` 在主场景渲染后逐项调用：

```
RPost 后处理顺序（推测，依据 RExec::post_* 调用顺序）
  ├─ renderSSAO()                              // SSAO（屏幕空间环境光遮蔽）
  ├─ post_ssr → RPost 无独立方法，由 RExec::post_ssr 调用
  ├─ post_composite_deferred                   // 延迟光照合成
  ├─ renderScattering(scene, light)            // 大气散射 / 天空背景 ★
  ├─ renderVolumetric(light, screen)           // 体积光
  ├─ renderFog(light)                          // 雾
  ├─ renderGlow(ret_texture)                   // 辉光
  ├─ renderLLNV(ret_texture, screen, grayMode) // 微光夜视
  ├─ renderRadar(ret_texture)                  // 雷达地图
  ├─ renderRadarWeather(scene, screen)         // 雷达气象
  ├─ renderDOF(ret_texture, screen)            // 景深
  ├─ renderHDR(light, screen, ...)             // HDR（曝光/十字星/散景/光束/镜头光晕）
  ├─ renderTAA(color, color_old, ...)          // 时域抗锯齿
  ├─ renderCompositePost(...)                  // 最终合成
  ├─ post_sharpen(screen)                      // 锐化
  └─ post_render(screen)                       // 输出到屏幕
```

## 3. 散射与天空背景实现（核心模块）

### 3.1 类协作

```
Render (持有 scattering_* 参数)
  ├─ m_scattering_light_color_lut_texture  // 光颜色 LUT
  ├─ m_scattering_sun_power/scale/angle/threshold/color  // 太阳参数
  └─ RPost::m_atmosphere_model (AtmosphereModel*)
       ├─ m_transmittance_texture          // 透射率 LUT
       ├─ m_scattering_texture             // 散射 LUT
       ├─ m_irradiance_texture             // 辐照度 LUT
       ├─ m_rayleigh_scattering / m_mie_scattering / m_solar_irradiance
       └─ init(radius_top, radius_bottom) → compute_transmittance / compute_single_scattering / compute_direct_irradiance

LightWorld (太阳光节点)
  ├─ m_usage == USEAGE_SUN                  // 身份：太阳
  └─ m_scattering == SCATTERING_GLOBAL      // 开关：启用散射
```

### 3.2 触发条件

`RExec::post_scattering(scene, screen)` 仅在以下条件同时满足时执行：

1. `Render::m_enable_environment == true`（`enable_environment = 1`）
2. 存在 `LightWorld` 节点且 `m_usage == USEAGE_SUN`、`m_scattering == SCATTERING_GLOBAL`
3. 当前视觉模式 `m_vision_mode` 不是 IR 等会跳过散射的模式

`RPost::renderScattering(scene, light)` 内部：

1. 从 `LightWorld` 取太阳方向、颜色
2. 调用 `AtmosphereModel::flushParamsToMaterial(mat)` 写入 `sun_direction`、`sun_color`、`sun_param`（power/scale/angle/threshold）
3. 调用 `AtmosphereModel::flushTexturesToMaterial(mat)` 绑定 `transmittance_texture`、`scattering_texture`、`irradiance_texture`
4. 渲染天空球/fullscreen quad，按透射率与散射 LUT 着色，输出到 `screen->color`

### 3.3 `AtmosphereModel` 预计算

`AtmosphereModel::init(radius_top, radius_bottom)` 后：

- `compute_transmittance()`：离屏渲染 `atmosphere_transmittance` 材质，生成透射率 LUT
- `compute_single_scattering()`：离屏渲染 `atmosphere_single_scattering` 材质，生成单次散射 LUT
- `compute_direct_irradiance()`：生成辐照度 LUT

参数来源：

| `AtmosphereModel` 成员 | `.world` `render` 段字段 |
|------------------------|--------------------------|
| `m_radius_top` / `m_radius_bottom` | `scattering_radius` |
| `m_rayleigh` | `scattering_rayleigh` |
| `m_rayleigh_scale_height` | `scattering_rayleigh_height` |
| `m_mie_angstrom_beta` | `scattering_mie_angstrom_beta` |
| `m_mie_angstrom_alpha` | `scattering_mie_angstrom_alpha` |
| `m_mie_single_scattering_albedo` | `scattering_mie_albedo` |
| `m_mie_scale_height` | `scattering_mie_height` |
| `m_sun_exposure` | `scattering_sun_exposure` |
| `m_moon_exposure` | `scattering_moon_exposure` |
| `m_sun_dir` / `m_moon_dir` | 由 `LightWorld` 节点方向提供 |

## 4. 渲染状态管理 `RState`

`RState` 是抽象基类，由各图形 API 后端继承实现（`D3D11Ext`、`GLExt`、`VulkanExt`）。它封装：

- **光栅化状态**：`m_depth_func`、`m_blend_op/src/dst`、`m_alpha_func`、`m_polygon_front/cull/fill`、`m_polygon_bias/slope`
- **资源绑定**：`m_shader`、`m_material`、`m_textures[24]`、`m_structured_buffers[16]`
- **渲染目标**：`m_env_buffers`、`m_screen`（`RenderScreen*`）、`m_rhi_viewport`
- **超采样**：`m_super_render`、`m_super_render_width/height`

关键接口：

- `clearStates()`：恢复默认 blend/depth/alpha/cull，清空 shader slot 与纹理
- `flushStates()`：提交延迟状态到底层 API
- `flushRender()`：提交渲染命令
- `flushGPU()`：显式等待 GPU 完成
- `setShaderParameter*()`：上传 shader 参数（int/float/double，标量/向量/数组）

`RExec` 通过 `setBufferMask`/`setDepthFunc`/`setBlendFunc`/`setAlphaFunc`/`setPolygonCull`/`setPolygonOffset` 等 pass 感知的状态设置函数，根据当前 `RENDER_PASS_TYPE` 从 `Material` 读取状态并下发到 `RState`。

## 5. 渲染通道 `RENDER_PASS_TYPE`

定义于 `IGBase.h`：

```cpp
enum RENDER_PASS_TYPE
{
    RENDER_PASS_NONE = -1,
    RENDER_PASS_WIREFRAME = 0,   // 线框
    RENDER_PASS_PRE_DEPTH,       // 深度预通道
    RENDER_PASS_DEFERRED,        // 延迟写入 G-Buffer
    RENDER_PASS_REFRACTION,      // 折射
    RENDER_PASS_AMBIENT,         // 环境光
    RENDER_PASS_LIGHT_POINT,     // 点光
    RENDER_PASS_LIGHT_OMNI,      // 全向光
    RENDER_PASS_LIGHT_PROJ,      // 投影光
    RENDER_PASS_LIGHT_WORLD,     // 全局光/太阳光
    RENDER_PASS_SHADOW,          // 阴影
    RENDER_PASS_POST,            // 后处理
    RENDER_PASS_OUTLINE,         // 轮廓
    RENDER_PASS_IR,              // 红外通道
    RENDER_NUM_PASSES,
};
```

`Object::setPassEnabled(tp, v)` 可按通道开关某个物体的渲染。`RExec::setMaterialStates(pass, mat)` 会根据 pass 设置对应的 blend/depth/cull 状态。

## 6. `RenderScreen` 结构

每帧渲染的渲染目标集合，由 `RExec::create_screen` 创建：

```cpp
struct RenderScreen
{
    int width, height;
    TextureRender* texture_render;          // 主 RT
    TextureRender* texture_render_deferred; // 延迟 RT
    TextureRender* post_texture_render;     // 后处理 RT
    Texture* color;                         // 当前颜色缓冲
    Texture* opacity_color;                 // 不透明颜色
    Texture* final_color;                   // 最终颜色
    Texture* opacity_depth;                 // 不透明深度（RGBA32F）
    Texture* current_depth;                 // 当前深度（D32F）
    GBuffer gbuffer;                        // G-Buffer
    RenderBuffers buffers;                  // 延迟光照缓冲
};
```

## 7. 线程模型与可见性剔除

### 7.1 `RScene::getIntersection`

```
RScene::getIntersection(bf, e)
  ├─ 遍历 World 节点
  ├─ add_node(bf, node)            // 视锥剔除后加入可见集合
  │    ├─ 递归 ObjectPrefab 内部节点
  │    ├─ add_light(light)
  │    └─ add_decal(decal)
  ├─ update_intersection()         // 多线程收集 surface
  │    └─ add_objects_cpu_thread   // CPU 任务并行
  └─ sort_surface()                // 按材质/距离排序
       ├─ m_opacity_surfaces       // 不透明
       ├─ m_transparent_surfaces   // 透明
       ├─ m_opacity_decals
       └─ m_transparent_decals
```

### 7.2 多线程

`RScene` 使用 `CPUTask`/`CPUTaskInfo` 将可见性剔除与 surface 收集分摊到 CPU 线程池，提升大场景性能。

## 8. 总结

引擎采用 **分层 + 模块化** 的渲染架构：

1. **应用层** `Render`：暴露全局参数与开关，由应用层（如 `NodeSnapShot`）通过 `setVisionMode`、`setEnableEnvironment` 等接口控制。
2. **调度层** `RExec`：组织一帧的 pass 顺序，管理相机栈与状态栈，调度 `RScene`/`RLights`/`RPost`。
3. **收集层** `RScene`：视锥剔除，产出可见 surface 列表。
4. **光照层** `RLights`：阴影贴图与延迟光照计算。
5. **后处理层** `RPost`：屏幕空间特效（SSAO/SSR/散射/HDR/TAA/DOF/雾/体积光/Glow/LLNV/Radar）。
6. **状态层** `RState`：抽象底层 API，由 D3D11/OpenGL/Vulkan 后端实现。
7. **大气模型** `AtmosphereModel`：预计算散射 LUT，供 `RPost::renderScattering` 使用。

**渲染路径**：默认延迟渲染（G-Buffer → 延迟光照 → 合成），透明物体走前向路径。散射/天空背景由 `LightWorld::SCATTERING_GLOBAL` 触发，经 `AtmosphereModel` 预计算 LUT + `RPost::renderScattering` 在后处理阶段合成。

**多后端支持**：`RState` 抽象层 + `d3d11/opengl/vulkan` 三个子目录的后端实现，使引擎可跨图形 API 运行。
